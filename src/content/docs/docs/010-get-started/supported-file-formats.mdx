# Supported File Formats

Pixodesk Animator Studio supports **three** animation file formats: **SVG, JSON for SVG** animation, and **JSON for Lottie** animation.

These formats are **interchangeable**. The editor can convert between them at any time, allowing you to switch formats depending on your target platform.


## SVG File Formats

Pixodesk Animator Studio supports three SVG formats.

### JSON File Format for SVG Animation

This is the most flexible and recommended format for SVG animation workflows.

All animation data, structure, and metadata are stored in a single JSON file. At runtime, JavaScript renders the SVG DOM and drives the animation playback.

This format is designed for modern web applications and integrates with Pixodesk runtime libraries:

- @pixodesk/svg-animator-web
- @pixodesk/svg-animator-react
- @pixodesk/svg-animator-vue


Use this format when you need maximum control, programmatic interaction, or framework integration.

The JSON format is SSR-safe and works well in modern rendering environments.

It can be used:
- in applications built with **frameworks** such as **React, Vue, Next.js, and Nuxt**, where animations may need to load dynamically or interact with application state.
- for **vanilla JavaScript and DOM** environments, allowing animations to be loaded dynamically and controlled through JavaScript APIs.
- with **static site generators and CMS platforms**, including tools such as **Astro, Jekyll, WordPress, and Shopify**.

---

### SVG File Format

A pre-rendered SVG file with animation embedded directly into the document.

This format produces a self-contained file that can run independently in modern browsers.

Pixodesk Animation supports several SVG animation modes.

#### SVG with CSS Keyframes

Animation is defined using CSS inside a `<style>` block within the SVG.

**Features**:

- No `<script>` tag required
- Pure CSS animation
- Ideal for simple, lightweight animations


---

#### SVG with JavaScript Triggers
Adds a minimal JavaScript fragment to the SVG to enable event-driven animations.

Supported **triggers** include:

- Click
- Hover
- Scroll
- Custom events


This mode allows animations to react to user interaction while keeping the file mostly self-contained.


----

#### SVG with JavaScript Animation
This mode embeds the Pixodesk runtime `@pixodesk/svg-animator-web` directly inside a `<script>` tag.

Animation playback can use:

**Web Animations API (WAAPI)** <br/>
Uses the browser's native animation engine for high performance.

**requestAnimationFrame**<br/>
Provides universal browser support for environments where WAAPI is not available.

This mode provides maximum compatibility and runtime flexibility within a single SVG file.

---


## Lottie File Format


A **Lottie JSON** animation file designed for cross-platform playback.

The file contains:
- Vector shapes
- Animation timelines
- Transform and keyframe data

Lottie files are typically used with the Lottie runtime players on web, mobile, and application platforms.

Pixodesk Animation Studio can save animations in Lottie JSON format for integration with standard Lottie playback environments.
