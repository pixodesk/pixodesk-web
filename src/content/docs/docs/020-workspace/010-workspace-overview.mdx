# Workspace Overview

The Pixodesk Animator workspace is divided into several fixed panels arranged around a central canvas. Each panel serves a specific role in creating and editing SVG animations.

```
┌─────────────────────────────────────────────────────────────┐
│  Menu Bar  (Edit / View / Object / Path / Tool / Window / Help) │
├─────────────────────────────────────────────────────────────┤
│  Toolbar  (context-sensitive left side + persistent right side) │
├───────┬────────────────────────────┬──────────────┬─────────┤
│ Tools │                            │  Properties  │Sections │
│ Panel │          Canvas            │  Panel       │Bar      │
│       │                            │              │         │
│       │                            ├──────────────┤         │
│       │                            │ Objects      │         │
│       │                            │ Panel        │         │
├───────┴────────────────────────────┴──────────────┴─────────┤
│  Timeline Panel                                              │
└─────────────────────────────────────────────────────────────┘
```

## Menu Bar

The menu bar at the very top provides access to all application commands organised into menus: **File**, **Edit**, **View**, **Object**, **Path**, **Tool**, **Window**, and **Help**.

## Canvas

The central working area where you draw, edit, and preview your animation. Rulers, grid, canvas outline, and background display can all be toggled from the Toolbar.

See [Canvas](/docs/canvas) for full details.

## Tools Panel

The vertical strip of tool buttons on the far left. Click a tool to activate it, or use keyboard shortcuts. The active tool determines what the left side of the Toolbar shows and how the canvas responds to mouse interaction.

See [Tools Panel](/docs/tools-panel) for full details.


## Toolbar

The horizontal bar directly below the menu bar. The **left side** is context-sensitive — its contents change depending on the active tool. The **right side** is persistent and always shows: Undo/Redo, Snap controls, Canvas options, Zoom, Layout, Dark/Light Theme, Show Preview Panel, and Export.

See [Toolbar](/docs/toolbar) for full details.





## Objects Panel

Located to the right of the Tools Panel, on the left side of the workspace. Contains six sections:

- **Object Tree** — the full SVG element hierarchy; select, rename, reorder, show, hide, and lock layers
- **Symbols** — reusable symbol definitions
- **Markers** — marker definitions for path endpoints
- **Patterns** — pattern fill definitions
- **Filters** — filter effect definitions
- **Used Colors** — all colors currently in use across the document

Each section can be expanded or collapsed. When expanded, drag its top edge to resize it vertically.

See [Objects Panel](/docs/objects-panel) for full details.

## Properties Panel

The panel on the right side of the workspace. Shows editable properties for the currently selected object — or document-level properties when the `<svg/>` root is selected. Content is divided into collapsible sections (Color, Fill, Stroke, Transform, Shape, etc.).

See [Properties Panel](/docs/properties-panel) for full details.

## Properties Sections Bar

The narrow vertical strip of icon buttons on the far right edge of the workspace. Each button toggles the visibility of a corresponding section in the Properties Panel (Color, Fill, Stroke, Appearance, Filter, Transform, Shape, Arrange, Path, DOM Attributes).

See [Properties Sections Bar](/docs/properties-sections-bar) for full details.

## Timeline Panel

The panel along the bottom of the workspace. Used to create, edit, and play back animations using keyframes. Divided into three areas:

- **Layer List** (left) — document layers and their animated property tracks
- **Keyframe Editor** (centre) — visual timeline with keyframe markers, easing mini charts, and inner loops
- **Chart Panel** (right) — Value, Velocity, and Acceleration easing curves

See [Timeline Panel](/docs/timeline-panel) for full details.

---

## Customising the Layout

All panels can be shown, hidden, or maximised to suit your workflow. Open the **Layout** dropdown in the Toolbar to access these options. Each panel option toggles its visibility on and off.

- **Maximize Canvas** — expands the canvas area by temporarily hiding all interface panels
- **Left Panel** — the [Objects Panel](/docs/objects-panel)
- **Bottom Panel** — the [Timeline Panel](/docs/timeline-panel)
- **Right Panel** — the [Properties Panel](/docs/properties-panel) and [Properties Sections Bar](/docs/properties-sections-bar)
- **Show Keyframes** — the Keyframe Editor within the Timeline Panel
- **Show Charts** — the Chart Panel within the Timeline Panel
