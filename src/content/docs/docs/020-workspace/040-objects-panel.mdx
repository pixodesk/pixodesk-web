# Objects Panel

The Objects Panel is located to the right of the [Tools Panel](./tools-panel), on the left side of the workspace. It provides a complete view of everything in your document — from the layer structure of your artwork to reusable definitions and shared colors.

The panel is divided into several sections. Each section can be **expanded** or **collapsed** by clicking its header. When a section is expanded, you can drag its **top edge** to resize it vertically — giving more or less space to that section relative to the others.

## Object Tree

The top section displays the full hierarchy of SVG elements in your document. Every shape, group, text, and symbol instance appears here as a named layer. You can select, rename, reorder, show, hide, and lock layers from this view.

See [Object Tree](./object-tree) for details.

## Symbols

Lists all symbol definitions stored in the document. Symbols are reusable objects — create one and place multiple instances across your artwork. Each instance can have independent position, scale, and opacity while sharing the same underlying definition.

Each symbol is shown as a **visual thumbnail** of its content wherever a preview is possible. If a symbol exists in the document but is not placed on the canvas, a **red triangle with an exclamation mark** appears next to the section header when the section is collapsed, indicating unused definitions are present. To remove an unused symbol, expand the Symbols section and click the **bin icon** next to it.

See [Symbols](./symbols) and [Working with Symbols](../../docs/symbols) for full details.

## Markers

Lists all marker definitions stored in the document. Markers are shapes attached to the start, middle, or end points of a path stroke — useful for arrowheads, dots, and decorative endpoints.

Each marker is shown as a **visual thumbnail** of its shape. If a marker exists but is not applied to any path, a **red triangle with an exclamation mark** appears next to the section header when collapsed. To remove an unused marker, expand the Markers section and click the **bin icon** next to it.

See [Markers](./markers) and [Working with Markers](../../docs/markers) for full details.

## Patterns

Lists all pattern definitions stored in the document. Patterns tile an object across a fill area. Once created, a pattern can be applied as a fill to any object.

Each pattern is shown as a **visual thumbnail** of its tile content. If a pattern exists but is not applied to any object, a **red triangle with an exclamation mark** appears next to the section header when collapsed. To remove an unused pattern, expand the Patterns section and click the **bin icon** next to it.

See [Patterns](./patterns) and [Working with Patterns](../../docs/patterns) for full details.

## Filters

Lists all filter definitions stored in the document. Filters apply visual effects (blur, shadow, color adjustments, etc.) to objects. Each filter can be applied to multiple objects simultaneously.

See [Filters](./filters) and [Working with Filters](../../docs/adding-filters) for full details.

## Used Colors Panel

Displays all colors currently in use across the document. Clicking a color selects it for quick reuse or replacement across objects.

See [Used Colors Panel](./used-colors-panel) for details.
