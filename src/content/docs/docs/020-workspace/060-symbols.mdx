# Symbols

The Symbols section is part of the [Objects Panel](./objects-panel). It lists all symbol definitions stored in the current document.

## What Is a Symbol

A symbol is a reusable object definition stored in the SVG `<defs>` section. Once created, you can place any number of **instances** of that symbol anywhere on the canvas. All instances share the same underlying artwork, so editing the symbol definition updates every instance at once.

Each instance can have its own position, scale, rotation, opacity, and fill/stroke overrides independently of other instances.

## Symbols Section

Each symbol in the list displays a **thumbnail preview** and its name. If a symbol is not used by any instance on the canvas, it is labeled **Unused**.

## Editing a Symbol

Double-click a symbol's thumbnail to enter **Symbol View** — an in-place editing mode where the canvas shows only the contents of that symbol. Exit Symbol View by clicking the **`...`** row at the top of the Object Tree.

## Full Documentation

For detailed instructions on creating, using, editing, converting, and deleting symbols, see the [Symbols](../../docs/symbols) documentation section.
