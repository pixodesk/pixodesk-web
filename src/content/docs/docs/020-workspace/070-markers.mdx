# Markers

The Markers section is part of the [Objects Panel](./objects-panel). It lists all marker definitions stored in the current document.

## What Is a Marker

A marker is a shape that is automatically placed along a path stroke at defined positions. Markers are stored in the SVG `<defs>` section and can be applied to any path. Three positions are supported:

- **Start** — placed at the first node of the path
- **Mid** — placed at every intermediate node
- **End** — placed at the last node of the path

Common uses include arrowheads, dots, and decorative endpoints on lines and paths.

## Markers Section

Each marker in the list displays a **thumbnail preview** and its name. Markers that are not applied to any path are labeled **Unused**.

## Editing a Marker

Double-click a marker's thumbnail to enter **Marker View** — an in-place editing mode showing only the contents of that marker. Exit Marker View by clicking the **`...`** row at the top of the Object Tree.

## Full Documentation

For detailed instructions on creating, applying, editing, and deleting markers, see the [Markers](../../docs/markers) documentation section.
