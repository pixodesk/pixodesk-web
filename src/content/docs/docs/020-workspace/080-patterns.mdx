# Patterns

The Patterns section is part of the [Objects Panel](./objects-panel). It lists all pattern definitions stored in the current document.

## What Is a Pattern

A pattern is a reusable tile definition stored in the SVG `<defs>` section. When applied as a fill, the pattern artwork is repeated (tiled) across the filled area of any object. After creating a pattern, you can control its translation, rotation, and scale independently for each object it is applied to.

## Patterns Section

Each pattern in the list displays a **thumbnail preview** and its name. Patterns that are not applied to any object are labeled **Unused**.

## Editing a Pattern

Double-click a pattern's thumbnail — or click the **Edit Pattern** button in the [Properties Panel](./properties-panel) when a pattern fill is active — to enter **Pattern View**. This is an in-place editing mode showing only the contents of that pattern. Exit Pattern View by clicking the **`...`** row at the top of the Object Tree.

## Full Documentation

For detailed instructions on creating, applying, editing, and deleting patterns, see the [Patterns](../../docs/patterns) documentation section.
