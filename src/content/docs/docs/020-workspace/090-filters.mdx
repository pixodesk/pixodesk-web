# Filters

The Filters section is part of the [Objects Panel](./objects-panel). It lists all filter definitions stored in the current document.

## What Is a Filter

A filter applies a visual effect to an object using SVG filter primitives. Effects include blur, drop shadow, color adjustments, distortion, and many others. Filters are stored in the SVG `<defs>` section and can be reused across multiple objects. When a filter is applied to several objects, changes to the filter definition affect all of them.

## Filters Section

Each filter in the list displays:

- The **filter name**
- The **number of objects** it is currently applied to
- An expandable tree of the **filter primitives** that make up the effect

## Editing a Filter

Unlike Symbols, Markers, and Patterns, filters do not have a dedicated "Filter View". Filters are edited inline — click the **Edit** button in the [Properties Panel](./properties-panel) next to the applied filter, or expand the filter in the Filters section and interact with its primitives directly.
