# Toolbar

The Toolbar is the horizontal bar above the canvas. The left side is context-sensitive — its content changes based on the active tool selected in the [Tools Panel](./tools-panel). The right side contains persistent controls that are always available regardless of the active tool.

## Persistent Controls

These buttons appear on the right side of the Toolbar at all times.

### Undo / Redo

- **Undo** `Ctrl/Cmd+Z` — reverse the last action
- **Redo** `Shift+Ctrl/Cmd+Z` — reapply the last undone action

### Snap

Two toggle buttons and a settings dropdown control snapping behaviour:

- **Snap to Other** — toggle snapping to other objects on the canvas
- **Snap to Step** — toggle snapping to grid intervals and angle steps
- **Snap settings** (dropdown) — detailed snap configuration:
  - **Snap/Align to Other** — enable object-to-object snapping and alignment
    - What is snapped: Bounding Box Corners and Midpoints, Shape Path Nodes, Control Points
    - Snap to: Bounding Box Corners and Midpoints, Shape Path Nodes, Page Borders and Midpoint
    - Align to: Bounding Box Corners and Midpoints, Shape Path Nodes, Page Borders and Midpoint
  - **Snap to Closest Point on Path** — snap to the nearest point along any path
  - **Snap threshold** — pixel distance within which snapping activates
  - **Snap to Step** — snap movement to a fixed grid interval (configurable step size)
  - **Snap Rotation to Angle Step** — constrain rotation to fixed angle increments

### Canvas

The **Canvas** dropdown controls what is shown on and around the canvas:

- **Show Ruler** — toggle the rulers along the top and left edges
- **Show Grid** — overlay a grid on the canvas
- **Show Canvas Outline** — show the canvas boundary outline
- **Clip Canvas Content** — hide objects outside the canvas boundary
- **Show Canvas Background** — show or hide the canvas background fill
- **Canvas Background** — color picker to set the canvas background color

### Zoom

The **Zoom** dropdown provides zoom shortcuts:

- **Zoom in**
- **Zoom out**
- **Zoom 100%** — reset to actual size
- **Zoom to Fit** — fit the content in the available space
- **Zoom to Page** — fit the canvas boundary in the view
- **Zoom to Selection** — zoom to the current selection
- **Zoom Timeline to Frame Range** — fit the timeline view to the animation duration

### Layout

The **Layout** dropdown controls panel and timeline visibility:

- **Maximize Canvas** — hide all panels to maximise the canvas area
- **Left Panel** — show or hide the Objects Panel (left side)
- **Bottom Panel** — show or hide the Timeline Panel (bottom)
- **Right Panel** — show or hide the Properties Panel (right side)
- **Show Keyframes** — toggle the Keyframe Editor within the Timeline Panel
- **Show Charts** — toggle the Chart Panel within the Timeline Panel

### Dark / Light Theme

Toggle between **dark** and **light** application themes.

### Show Preview Panel

Open or close the [Preview Panel](./preview-panel) — an inline browser frame that renders your animation live without saving.

### Export

Open the export dialog to save or download the animation in the configured file format. See the [Export](../../docs/export) documentation for details.

## Selection Tool

Active when the **Selection** `S` or **Transform** `T` or **Hand** `H` tool is selected.

- **Group** / **Ungroup** — group or ungroup selected objects
- **Make Symbol** — convert selection into a reusable symbol
- **Make Marker** — convert selection into a marker definition
- **Make Pattern** — convert selection into a pattern definition
- **Arrange** — bring forward, send backward, bring to front, send to back
- **Align** — align selected objects relative to each other or the page
- **Distribute** — distribute selected objects with equal spacing
- **Flip** — flip horizontally or vertically
- **Move Along Path** — attach selected object to a path for motion
- **Mask** — apply or remove a mask
- **Path operations** — Union, Subtract, Intersect, Exclude, Divide

## Node Tool

Active when the **Node** `N` tool is selected.

- **Add Node** — insert a new node on the selected path
- **Remove Node** — delete the selected node(s)
- **Break at Points** — split the path at the selected node(s)
- **Path Start** — set the selected node as the path start
- **Reverse Path** — reverse the direction of the path
- **Node type buttons** — toggle node type: Cusp, Smooth, Symmetric, Auto-Smooth
- **Path operations** — Union, Subtract, Intersect, Exclude, Divide
- **Align / Distribute nodes** — align or distribute selected nodes

## Round Corner Tool

Active when the **Round Corner** `C` tool is selected.

- **Corner Radius** — numeric input for the rounding radius
- **Corner Type** — Round, Bevel, or Inverted Round
- **Convert to Curves** — convert the shape to a fully editable path

## Shape Builder Tool

Active when the **Shape Builder** `B` tool is selected.

- **Mode buttons** — Add, Remove, All, Subtract, Intersect, Exclude, Deselect

## Repeater Tool

Active when the **Repeater** `Y` tool is selected.

- **Count** — number of copies in the repeat
- **Add Circular Repeat** — create a circular repeating pattern
- **Add Linear Repeat** — create a linear repeating pattern
- **Add one clone** / **Remove one clone** — adjust the number of clones
- **Cancel Repeat** — exit the repeater mode

## Spray Tool

Active when the **Spray** tool is selected.

- **Spray Radius** — the area radius in which copies are sprayed
- **Amount** — number of copies sprayed per stroke
- **Rotation** — rotation variation applied to copies
- **Min Scale** / **Max Scale** — size range for sprayed copies
- **Min Opacity** / **Max Opacity** — opacity range for sprayed copies

## Gradient Tool

Active when the **Gradient** `G` tool is selected.

- **Focal Point** — toggle the focal point for radial gradients on or off

## Pen and Freehand Tools

Active when the **Pen** `P` or **Freehand** `F` tool is selected.

- **Fill color** — color picker for the fill
- **Stroke color** — color picker for the stroke
- **Stroke Width** — numeric input for stroke thickness
- **Path operations** (Pen only) — Union, Subtract, Intersect, Exclude, Divide

## Shape Drawing Tools

Active when the **Ellipse** `E`, **Rectangle** `R`, or **Shape** `W` tool is selected.

- **Fill color** — color picker for the fill
- **Stroke color** — color picker for the stroke
- **Stroke Width** — numeric input for stroke thickness
- **Shape Type** (Shape Tool only) — Star, Polygon, or Spiral

## Text Tool

Active when the **Text** `X` tool is selected.

- **Fill color** — color picker for the text fill
- **Font Type** — select between font types
- **Font Family** — choose the typeface
- **Font Style** — bold, italic, and other style variants
- **Font Size** — numeric input for text size
- **Put Text on Path** — attach the text to a selected path
- **Text to Bezier Shape** — convert the text to an editable vector path

## Page Tool

Active when the **Page** tool is selected.

The toolbar shows no additional context-sensitive controls for this tool. Use the persistent [Canvas](#canvas), [Zoom](#zoom), and [Layout](#layout) dropdowns on the right side of the toolbar to adjust the view.
