# Used Colors Panel

The Used Colors panel is the bottom section of the [Objects Panel](./objects-panel). It shows every color currently applied anywhere in the document — across fills, strokes, and gradients of all objects.

## What It Shows

Each color swatch represents a unique color value in use. The panel updates automatically as you add, change, or remove colors in your artwork.

## Using a Color from the Panel

Click any color swatch to select it as the active color. The selected color can then be applied to the fill or stroke of a selected object using the [Properties Panel](./properties-panel) or the color picker in the [Toolbar](./toolbar).

## Replacing a Color

The Used Colors panel makes it easy to identify and reuse consistent colors across your document. If you need to update a color globally, select objects that use it and apply the new color — the panel reflects the change immediately.
