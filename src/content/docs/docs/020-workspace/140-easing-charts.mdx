# Easing Charts

The Chart Panel is the right section of the [Timeline Panel](./timeline-panel). It displays animation curves for the selected properties, allowing precise control over easing and timing.

## Chart Types

The Chart Panel shows up to three charts simultaneously, each with a watermark label:

- **Value** — how the property value changes over time; the curve shape is the interpolation path between keyframes
- **Velocity** `ƒ′(t)` — the rate of change; useful for identifying acceleration and deceleration
- **Acceleration** `ƒ′′(t)` — the second derivative; useful for spotting abrupt changes in motion

The Value chart is always visible. Use the More (⋮) menu in the Chart Panel to toggle the **Velocity** and **Acceleration** charts on or off.

When you click a segment between two keyframes in the [Keyframe Timeline](./keyframe-timeline), the Chart Panel updates to show the easing curve for that specific segment.

## Editing Easing

Drag the curve **handles** directly in the chart to adjust the easing between keyframes. Changes are reflected in real time on the canvas.

## Multiple Properties

When multiple animated properties are selected, their curves are displayed together in the same chart. This makes it easy to compare and synchronise the timing of different properties.

## Chart Panel More Menu

The Chart Panel More (⋮) menu contains:

- **Show Velocity Chart** — toggles the Velocity `ƒ′(t)` chart
- **Show Acceleration Chart** — toggles the Acceleration `ƒ′′(t)` chart
- **Show values on multiple scales** — when multiple properties with different value ranges are shown together, scales each curve independently so all shapes are visible

For detailed information on easing presets and the Easing Function panel, see the [Easing Charts](../../docs/easing-charts-overview) section.
