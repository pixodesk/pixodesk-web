# Properties Sections Bar

The Properties Sections Bar is the narrow vertical strip of icon buttons on the far right edge of the workspace, beside the [Properties Panel](./properties-panel). It controls which sections are visible in the Properties Panel for the currently selected object.

## How It Works

Each button in the bar corresponds to a section in the Properties Panel. Clicking a button **toggles** that section on or off:

- **Highlighted** — the section is currently visible in the Properties Panel.
- **Dimmed** — the section is hidden.

The set of available buttons changes depending on the **type of object selected**. Sections that are not relevant to the current selection do not appear in the bar.

## Sections

### Color

Shows the combined fill and stroke color picker with R/G/B/H/S/L/A input fields. Lets you quickly switch between editing the fill color and the stroke color.

### Fill

Shows the fill type selector (solid, linear gradient, radial gradient, pattern, none) and its related settings.

### Stroke

Shows stroke color, width, dash pattern, line cap, and line join settings.

### Appearance

Shows opacity and other visual appearance settings for the selected shape or group.

### Filter

Shows applied filters and the **Add Filter** button. Each applied filter appears as its own collapsible entry with an **Edit** button.

### Transform

Shows position (X/Y), rotation, scale, and transform origin for the selected object.

### Shape

Shows shape-specific size and geometry options — for example, **Rectangle Size** for rectangles or **Ellipse Size** for ellipses. Only available for shape objects.

### Arrange

Shows alignment and distribution controls relative to other selected objects or to the page.

### Path

Shows path node operations — **Align Points** and **Distribute Points**. Only available for objects with editable paths.

### DOM Attributes

Shows the SVG element's `id` and `class` attributes, allowing you to set them directly. Hidden by default — click its icon in the bar to show it.
