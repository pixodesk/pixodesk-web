# Open Existing Documents

Pixodesk Animator Studio allows you to open existing animation documents in several ways. You can open animation files created in Pixodesk Animator Studio, as well as supported SVG and Lottie JSON files.

## Drag and Drop

Drag an animation file from your file system and drop it directly onto the Pixodesk Animator Studio window.

When you drop a file, a dialog appears with options for how the file should be handled:

### Open File

Opens the dropped file as a new document. If the current window is empty, the file opens in the same window. If a project is already open, the file opens in a new window.

### Add Content

Imports the dropped animation into the currently open document. The imported animation is added as a group, preserving its structure and animation data.

### Replace Content

Replaces all existing content in the current document with the content from the dropped file. The previous animation content is removed.

## Open from the File System

Double-click an animation file in File Explorer (Windows) or Finder (macOS) to open it in Pixodesk Animator Studio.

## Context Menu

Right-click an animation file in File Explorer (Windows) or Finder (macOS) and choose **Open With → Pixodesk Animator Studio**.

## Open Command

Choose **File → Open** from the application menu, then navigate to the file you want to open.

## Open Recent

Choose **File → Open Recent** and select a document from the list of recently opened files.
