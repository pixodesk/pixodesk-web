# Import SVG and Lottie Files

Pixodesk Animator Studio allows you to import existing SVG and Lottie JSON animations into your current document. Imported files are added to the canvas while preserving their vector structure and animation data wherever possible.

## Drag and Drop

Drag the animation file from your file system and drop it directly onto the Pixodesk Animator Studio window. The file is imported into the current document.

## Import Command

Choose **File → Import** from the application menu, then navigate to the file you want to import.

After importing, the animation elements appear on the canvas and can be edited like any other objects in the document.
