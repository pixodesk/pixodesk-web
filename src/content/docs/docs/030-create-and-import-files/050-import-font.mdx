# Import Font (.TTF)

You can import custom fonts into Pixodesk Animator Studio for use in text layers.

To import a font file, choose **File → Import Font Files (TTF)** from the application menu.

Once imported, the font becomes available in the Font section of the [Properties Panel](../../docs/properties-panel) when a text layer is selected.
