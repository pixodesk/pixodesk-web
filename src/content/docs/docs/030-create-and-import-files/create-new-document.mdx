# Create New Document


To start working with Pixodesk Animator Studio, create a new animation document.

When you open the application, **choose the file format** you want to work with. 

**Pixodesk Animator Studio supports**:
- JSON file format for Lottie animation
- JSON file format for SVG animation
- SVG file format with CSS keyframes
- SVG file format with JavaScript triggers
- SVG file format with JavaScript animation


These file formats described in <span style="color: var(--sl-color-accent-high);">[Supported file formats](/docs/supported-file-formats)</span> section.

The selected format defines the initial structure and saving settings of the document. However, file formats are **interchangeable**, and you can change the format later at any time during the project.

If you are creating an animation intended for multiple platforms, you can start with any format and convert it later depending on your final deployment requirements.

To create a new document from the application menu, choose:

**File → New**


A new animation document will open with the selected format and default document settings.
