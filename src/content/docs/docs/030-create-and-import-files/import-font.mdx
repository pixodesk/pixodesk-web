# Import Font (.TTF)

You can import custom fonts into Pixodesk Animation for use in text layers.

To import a font file, choose:

File → Import Font Files (TTF)

Once imported, the font becomes **available** in the Font section of the Properties Panel **when a text layer is selected** on the canvas.

Imported fonts can be used for text rendering and animation within your document.
