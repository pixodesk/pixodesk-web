# Import Images

Pixodesk Animator Studio allows you to import raster images into your animation. 

Images can be imported using the following methods.

## Drag and Drop

Drag an image file from your file system and drop it directly onto the Pixodesk Animator Studio application window. 

The image will appear on the canvas as a new layer.

## Import Command

Choose `File → Import` from the application menu, then navigate to the image file you want to import.

## Copy and Paste Images or Screenshots

You can paste images directly from other applications.

- Open Pixodesk Animator Studio Pro.
- Copy an image or take a screenshot from another application.
- Choose Edit → Paste or use the standard paste keyboard shortcut.


The image will be inserted into the document as a new image layer on the canvas.
