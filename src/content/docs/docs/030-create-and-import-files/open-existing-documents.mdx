# Open Existing Document

Pixodesk Animator Studio allows you to open existing animation documents in several ways.

You can open animation files created in Pixodesk Animator Studio, as well as supported SVG and Lottie JSON files.

To open an existing document, use one of the following methods:

## Drag and drop

Drag the animation file from your file system and drop it directly onto the Pixodesk Animator Studio application window.

When you drop a file into the application, a dialog appears with several options for how the file should be handled:

#### Open File

Opens the dropped file as a document. 

If the current application window is empty, the file opens in the same window. If a project is already open, the file opens in a new application window.

#### Add Content

Imports the dropped animation into the currently open document. 

The imported animation is added to the project as a Group, preserving its structure and animation data.

#### Replace Content

Replaces all existing content in the current document with the animation from the dropped file. 

This option keeps the current document open but removes the previous animation content.


## Open from the file system

Double-click the animation file in File Explorer (Windows) or Finder (macOS) to open it in Pixodesk Animator Studio.

## Context menu

Right-click the animation file in File Explorer (Windows) or Finder (macOS) and choose Open With → Pixodesk Animator Studio.

## Open command

Choose File → Open from the application menu, then navigate to the animation file you want to open.

## Open Recent

Choose File → Open Recent, and select a document from the list of recently opened projects.
