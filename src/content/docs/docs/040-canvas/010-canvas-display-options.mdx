# Canvas Display Options

Canvas display options control what is shown on and around the canvas. Access them from the **Canvas** dropdown in the top [Toolbar](../../docs/toolbar#canvas).

## Ruler

**Show Ruler** displays rulers along the top and left edges of the canvas. Rulers show measurements in the current document unit and help with precise object placement.

## Grid

**Show Grid** overlays a grid on the canvas as a visual alignment aid. The grid does not affect the final output.

Two grid styles are available:

- **Dot Grid** — displays the grid as evenly spaced dots
- **Line Grid** — displays the grid as continuous horizontal and vertical lines

Switch between styles in the Canvas dropdown.

## Canvas Outline

**Show Canvas Outline** draws a border around the canvas boundary, making it easy to see where the document edges are.

## Clip Canvas Content

**Clip Canvas Content** hides any objects that extend beyond the canvas boundary. When disabled, objects outside the canvas remain visible in the editor but are cropped in the exported output.

## Canvas Background

**Show Canvas Background** toggles the display of a solid background color behind the canvas.

**Canvas Background** opens a color picker to set the background color. This background is only a display aid — it is not part of the SVG document and does not appear in exports unless explicitly added as a shape.
