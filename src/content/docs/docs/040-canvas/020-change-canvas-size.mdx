# Change Canvas Size

You can change the canvas size using two methods.

## Method 1 — Properties Panel

Select the **`<svg/>`** root element at the top of the [Object Tree](../../docs/object-tree), or deselect all objects so that document properties are shown in the [Properties Panel](../../docs/properties-panel).

Locate the **Content Size** controls under the **View Box** section and enter the desired width and height values. Enable the **lock** icon to scale width and height proportionally, or disable it to edit them independently.

## Method 2 — Page Tool

Select the **Page Tool** from the [Tools Panel](../../docs/tools-panel).

Drag any corner of the canvas boundary directly on the canvas to resize it interactively.
