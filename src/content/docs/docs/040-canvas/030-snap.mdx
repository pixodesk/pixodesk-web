# Snap

The Snap system helps align objects, nodes, and control points precisely when moving or editing elements.

When snapping is enabled, objects automatically align to nearby geometry, grid points, or other reference elements.

You can add next snap options:

## Snap / Align to Other

Enables snapping behavior between objects and reference points.

### What Snapped / Aligned

Defines which elements of your object can participate in snapping:

**Bounding Box Corners and Midpoint**<br/>
**Shape Path Nodes**<br/>
**Control Points**<br/>



### Snap to Other

Defines which elements of other objects your objects can snap to:

**Bounding Box Corners and Midpoint**<br/>
**Shape Path Nodes**<br/>
**Page Borders and Midpoint**<br/>



### Align with Other

Controls alignment behavior relative to nearby elements.

**Bounding Box Corners and Midpoint**<br/>
**Shape Path Nodes**<br/>
**Page Borders and Midpoint**<br/>

**Snap to Closest Point on Path** <br/>
Snaps objects or nodes to the nearest location along a path.

**Snap Screen Threshold** <br/>
Defines the distance (in screen pixels) within which snapping becomes active.

## Snap to Step

Snaps movement or transformation to defined increments.

**Snap to Grid** <br/>
Aligns objects to the visible grid.

**Grid Step** <br/>
Defines the spacing between grid snap points.

**Snap Rotation to Angle Step** <br/>
Constrains rotation to specific angle increments.

**Angle Step** <br/>
Defines the rotation step value.
