# Canvas

The Canvas represents the visible working area where you create and edit your artwork and animations.

Canvas display settings can be configured from the Canvas Settings dropdown in the toolbar. 

These options let you control the visibility of the ruler, grid, canvas background, and more.

## Canvas Options

### Show Ruler

Displays rulers along the edges of the canvas. Rulers help measure distances and assist with precise object placement.

### Show Grid

Displays a grid overlay on the canvas that helps align objects visually.

### Dot Grid

Displays the grid as points (dots) instead of lines.

### Line Grid

Displays the grid as continuous horizontal and vertical lines.

### Show Canvas Outline

Shows the border of the canvas area.

### Clip Canvas Content

Restricts visible content to the canvas boundaries. Objects that extend beyond the canvas will be hidden.

### Show Canvas Background

Displays a background color behind the canvas.

### Canvas Background

Allows you to select the color used as the canvas background.
