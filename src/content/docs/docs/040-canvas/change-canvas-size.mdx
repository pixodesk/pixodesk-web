Change Canvas Size
You can change the canvas size using two methods.
Method 1 — Content Size (Properties Panel)
Open the Properties Panel.


Locate the Content Size controls.


The Content Size option is visible when:
no objects are selected, or


the <svg /> root element is selected in the Layer Tree panel.


Unlock the lock if you want to change the width and height independently.

Method 2 — Page Tool
Select the Page Tool from the Toolbar Panel.


Drag any corner of the canvas to adjust its size.


This method allows you to resize the canvas interactively directly on the screen.
