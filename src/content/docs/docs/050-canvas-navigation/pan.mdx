# Pan

Panning moves the canvas view without changing zoom level or affecting objects. Use it to scroll around a large document or to reposition the view after zooming in.

## How to Pan

- **Hand Tool** `H` — select the Hand Tool, then click and drag anywhere on the canvas to pan freely
- **Space + drag** — hold `Space` with any tool active to temporarily switch to the Hand Tool; release `Space` to return to the previous tool
- **Middle mouse button drag** — hold the middle mouse button and drag to pan
- **Scroll** — scroll vertically with the mouse wheel; hold `Shift` to scroll horizontally
