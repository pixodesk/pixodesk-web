# Zoom

Zoom controls allow you to adjust the magnification level of the canvas and timeline.

These options help you inspect details or view the entire composition.

You can edit next Zoom Options:

### Zoom In

Increases the canvas magnification.

### Zoom Out

Decreases the canvas magnification.

### Zoom 100%

Displays the canvas at its actual size.

### Zoom to Fit

Adjusts the zoom level so the entire canvas fits inside the application window.

### Zoom to Page

Zooms the view to match the page boundaries.

### Zoom to Selection

Zooms the view to focus on the currently selected objects.

### Zoom Timeline to Frame Range

Adjusts the timeline zoom to display the full frame range of the animation.
