# Drawing

Pixodesk Animator Studio provides a set of drawing tools for creating vector graphics directly on the canvas. These tools allow you to build shapes, text, and custom paths that can later be animated in the timeline.

## Tools Panel

The Tools Panel is the vertical toolbar on the left side of the workspace. Tools are grouped by function, separated by a divider.

**Selection and editing:**

| Tool | Shortcut | Description |
|------|----------|-------------|
| Selection Tool | S | Select and move objects |
| Node Tool | N | Edit individual bezier nodes on paths |
| Round Corner | C | Selectively round corners on vector shapes |
| Shape Builder | B | Merge, subtract, and extract overlapping areas of shapes |
| Transform Tool | T | Scale and rotate objects using a transform box |

**Object tools:**

| Tool | Shortcut | Description |
|------|----------|-------------|
| Repeater Tool | Y | Create radial or linear arrays of an object |
| Spray | — | Distribute multiple instances of an object across the canvas |
| Gradient Tool | G | Create and edit gradient fills |
| Hand Tool | H | Pan the canvas |

**Drawing tools:**

| Tool | Shortcut | Description |
|------|----------|-------------|
| Pen Tool | P | Draw freeform Bézier paths and curves |
| Freehand Tool | F | Draw paths by freehand, converted to smooth bezier curves |
| Ellipse Tool | E | Draw ellipses and circles |
| Rectangle Tool | R | Draw rectangles and squares |
| Shape Tool | W | Draw stars, polygons, or spirals — select the sub-type in the top toolbar |
| Text Tool | X | Create and edit text elements |

## Shape Tool Sub-types

When the Shape Tool (W) is active, three sub-type buttons appear in the top toolbar:

- **Star** — creates a star shape with a configurable number of points
- **Polygon** — creates a regular polygon with a configurable number of sides
- **Spiral** — creates a spiral shape with a configurable number of turns

## Grouping

Objects can be grouped to behave as a single unit, making it easier to move, transform, and manage them together. See [Groups](./groups).
