# Round Corners

Rectangles and other vector shapes can have rounded corners.

You can control corner rounding in the Properties Panel under the Shape section.

## Corner Radius

Defines the radius used to round the corners of the shape.

The lock control allows you to link or unlink the horizontal and vertical radius values:

Locked — both values change proportionally


Unlocked — X and Y radius values can be adjusted independently




## Round Corner Tool

Pixodesk Animator Studio also provides a Round Corner Tool (C) located in the Tools Panel. This tool allows selective rounding of individual corners on vector shapes.

When the Round Corner Tool is active, additional options appear in the Top Panel.

### Corner Types

You can choose the style of the corner:

Round — smooth circular rounding

Bevel — straight edge cut across the corner

Inverted Round — concave rounded corner

### Corner Radius

Specifies the rounding radius applied to selected corners.

### Editing Multiple Corners

You can apply corner settings to multiple corners simultaneously.

Hold Shift to select multiple corners of a shape

Adjust the radius in the Top Panel to apply the same value to all selected corners

You can also copy and paste corner radius values between corners by copying the value from the radius input field and applying it to other selected corners.

### Editing Corners on the Canvas

Corners can also be edited directly on the canvas.

Drag the corner of the shape to interactively adjust the corner radius until the desired shape is achieved.
