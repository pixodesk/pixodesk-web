# Bézier Paths

Pixodesk Animator Studio uses Bézier paths to create custom vector shapes and curves. Paths consist of nodes (points) connected by segments, which can be straight or curved.

You can create paths using the Pen Tool (P). To edit existing paths and move individual nodes, use the Node Tool (N).



The Pen tool draws lines and curves. Click on the canvas to start a path. After that, each click will add a corner node to the path. Press and drag adds a curved node. Double-clicking ends the path. To create a closed path, click the start node of the path.

The Pen tool can also be used to connect open paths to each other. Select the first path's node and then select the second path's node to create a connecting segment.





## Pen Tool

The Pen Tool allows you to draw precise straight lines and curved paths.

To start drawing, click on the canvas to create the first node of a path. Each additional click adds another node connected by a line segment.

Creating Straight Segments

Click and release on the canvas to create a corner point.

Corner points produce straight line segments and do not include control handles.



## Creating Curved Segments

Click and drag to create a curved node.

The distance you drag determines the length (strength) of the curve.


The direction you drag determines the angle of the curve.


Curved nodes include control handles that define the shape of the Bézier curve.


## Constraining Angles

Hold the Shift key while dragging to constrain lines or control handles to 90-degree angles. This helps maintain precise alignment when creating paths.




## Ending a Path

You can finish drawing a path using one of the following methods:

Double-click on the canvas


Press the Escape key


To create a closed path, click the starting node of the path.


## Connecting Paths

You can connect open paths within a single shape or between multiple shapes.

Closing a single open path

Select the first and last nodes of an open shape and connect them to form a closed shape.

Connecting Two Open Paths

Select the two paths that you want to connect.


Select the Pen Tool.


Click the open node of the first path.


Click the open node of the second path.


A new segment is created, connecting the two paths into a single continuous path.
