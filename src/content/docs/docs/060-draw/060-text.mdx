# Text

You can create text elements using the Text Tool.

Select the Text Tool (X) from the Tools Panel, click on the canvas, and type your text. A new text layer will be created. The text can be edited directly on the canvas.

Text appearance and layout can be adjusted in the Properties Panel.



## Text Properties

Font Source

Source

Defines where the font is loaded from.

Font Asset File (.ttf) — uses a font file that has been imported into the project.


Browser Font — uses system fonts available on the computer.




Font Family and Style

Name

Selects the font family used by the text.

Weight

For Font Asset File, choose the available font style from the dropdown menu.


For Browser Font, select the font weight and optionally enable the italic style using the toggle button.


Available styles for Font Asset Files depend on the styles included in the imported font file.


Font Size

Size

Defines the size of the text characters.

The value can be expressed using several units, including:

px — pixels


em — relative to the current font size


ex — relative to the height of the lowercase "x"

rem — relative to the root font size


% — percentage relative to the parent element


pt — typographic points









Text Decoration

The Decoration controls allow you to apply standard text decoration styles.

Available options include:

Underline — draws a line below the text


Overline — draws a line above the text


Line-through — draws a line through the middle of the text


Multiple decorations can be applied simultaneously.


Text Transform

Transform controls automatic letter case conversion.

Available options include:

None — text appears exactly as typed


Uppercase — converts all characters to uppercase


Lowercase — converts all characters to lowercase


Capitalize — capitalizes the first letter of each word




Text Anchor (Alignment)

Anchor controls the horizontal alignment of the text relative to its starting point.

Options include:

Start — text is aligned from the starting point (left-aligned in most languages)


Middle — text is centered around the starting point


End — text is aligned to the end of the text string (right-aligned)




## Character Spacing

Letter Spacing

Controls the spacing between individual characters.

Increasing this value spreads the characters further apart, while decreasing it brings them closer together.

Word Spacing

Controls the spacing between words in the text.



Text Position

Start (x / y)

Defines the starting position of the text on the canvas.

x — horizontal position


y — vertical position




Text Offset

Offset (dx / dy)

Applies an additional positional offset to the text.

dx — horizontal offset


dy — vertical offset


This allows fine adjustments to text placement without modifying the original starting coordinates.
