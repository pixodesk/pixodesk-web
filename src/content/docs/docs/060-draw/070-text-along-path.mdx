# Text Along Path

Pixodesk Animator Studio provides several ways to place or move elements along a path. The available options depend on the selected tool and the selected layers.


## Move Element Along Path

This option is available in the Top Panel when:

two layers are selected, and


the Select Tool is active in the Toolbar Panel.


The top layer in the Layer Panel will move along the path of the layer underneath it. This allows you to position or animate an object along an existing path.


## Put Text on Path

This option is available in the Top Panel when:

a text layer and a path or shape layer are selected, and


the Text Tool is active.


The text will follow the selected path or shape instead of appearing in a straight line.


## Text Along Path (Property Panel)

This option is available in the Properties Panel when creating or editing text using the Text Tool.

When Text Along Path is enabled, the text follows a curved path instead of a straight line.

You can modify the shape of the path by adjusting its nodes or control points, which automatically updates the layout of the text along the curve.

Use the Create Path Shape button next to Text Along Path if you need to generate a path that matches the exact curve of the text. This path can then be edited or reused for other objects.







Move Text Along Path 



You can adjust the position of text along a path using the Offset property.

Select the text object, then change the Offset value in the Layout section of the Properties Panel to move the text along the path.
