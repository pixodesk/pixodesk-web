# Stars

You can create star shapes using the Shape Tool (W) from the Tools Panel. With the Shape Tool active, select the **Star** sub-type from the top toolbar.

Click and drag on the canvas to draw a star. Hold the Shift key while drawing to constrain the rotation to 30-degree increments, allowing you to align the star precisely and create perfectly pointed stars in the desired direction.

After creating the shape, you can adjust its appearance using the Properties Panel.

## Star Properties

**Points Count**

Defines the number of points (spikes) that form the star.

Increasing this value creates a star with more points, while decreasing it produces a simpler star shape.
