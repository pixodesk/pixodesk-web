# Polygons

You can create polygon shapes using the Shape Tool (W) from the Tools Panel. With the Shape Tool active, select the **Polygon** sub-type from the top toolbar.

Click and drag on the canvas to draw a polygon. Hold the Shift key while drawing to constrain the rotation to 30-degree increments, allowing you to align the polygon precisely.

After creating the shape, you can adjust its appearance using the Properties Panel.

## Polygon Properties

**Points Count**

Defines the number of sides (vertices) of the polygon.

Increasing this value creates polygons with more sides, while decreasing it produces simpler shapes such as triangles or pentagons.
