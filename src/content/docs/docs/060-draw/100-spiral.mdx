# Spirals

You can create spiral shapes using the Shape Tool (W) from the Tools Panel. With the Shape Tool active, select the **Spiral** sub-type from the top toolbar.

Click and drag on the canvas to draw a spiral. Hold the Shift key while drawing to constrain the rotation to 30-degree increments, allowing you to align the spiral precisely.

After creating the shape, you can adjust its appearance using the Properties Panel.

## Spiral Properties

**Points Count**

Defines the number of turns in the spiral.

Increasing this value adds more rotations, making the spiral longer and more complex.
