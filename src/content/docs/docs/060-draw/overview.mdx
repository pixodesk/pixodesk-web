# Drawing


Pixodesk Animation provides a set of drawing tools for creating vector graphics directly on the canvas. These tools allow you to build shapes, text, and custom paths that can later be animated in the timeline.

You can draw basic vector shapes such as rectangles, ellipses, stars, polygons, spirals, paths, and text.

In addition to standard drawing tools, Pixodesk Animation includes advanced tools such as Shape Builder, Repeater, and Spray, which help create complex visual structures quickly. These tools make it easier to achieve precise and unique visual results that would otherwise require significant manual drawing and arrangement.
