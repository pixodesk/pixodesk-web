# Polygons

You can create polygon shapes using the Polygon Tool from the Toolbar Panel.

Click and drag on the canvas to draw a polygon. Hold the Shift key while drawing to constrain the rotation to 30-degree increments, allowing you to align the polygon precisely.

After creating the shape, you can adjust its appearance using the Properties Panel.

When a Polygon shape is selected, the following options become available in the Shape section of the Properties Panel.



## Polygon Properties

Points Count

Defines the number of sides (vertices) of the polygon.

Increasing this value creates polygons with more sides, while decreasing it produces simpler shapes such as triangles or pentagons.



Radius

Defines the distance from the center of the polygon to its outer vertices.

Changing this value adjusts the overall size of the polygon.



Roundness

Controls the roundness of the polygon corners.

0% produces sharp corners





Higher values create smoother, rounded corners







Angle

Defines the rotation angle of the polygon.

Changing this value rotates the polygon around its center.
