# Spirals

You can create spiral shapes using the Spiral Tool from the Toolbar Panel.

Click and drag on the canvas to draw a spiral. Hold the Shift key while drawing to constrain the rotation to 30-degree increments, allowing you to align the spiral precisely.

After creating the shape, you can adjust its appearance using the Properties Panel.

When a Spiral shape is selected, the following options become available in the Shape section of the Properties Panel.

## Spiral Properties

Inner Radius

Defines the starting radius of the spiral from its center.

Increasing this value moves the beginning of the spiral farther from the center, creating a larger inner gap.



Radius Increment

Controls how much the radius increases with each turn of the spiral.

Higher values create a spiral that expands more quickly, while smaller values produce a tighter spiral.



Roundness

Controls the smoothness of the spiral segments.

Lower values produce sharper transitions between segments, while higher values create smoother curves.



Start Angle

Defines the initial rotation angle of the spiral.

Changing this value rotates the spiral around its center and determines the direction where the spiral begins.



Turns Count

Specifies the number of full turns in the spiral.

Increasing this value adds more rotations to the spiral, making it longer and more complex.



Segments in Turn

Defines how many segments are used to construct each turn of the spiral.

Higher values create smoother spirals with more detailed curves, while lower values produce a more angular appearance.
