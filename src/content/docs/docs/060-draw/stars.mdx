# Stars

You can create star shapes using the Star Tool from the Toolbar Panel.

Click and drag on the canvas to draw a star. Hold the Shift key while drawing to constrain the rotation to 30-degree increments, allowing you to align the star precisely and create perfectly pointed stars in the desired direction.

After creating the shape, you can adjust its appearance using the Properties Panel.

When a Star shape is selected, the following options become available in the Shape section of the Properties Panel.




## Star Properties

Points Count

Defines the number of points (spikes) that form the star.

Increasing this value creates a star with more points, while decreasing it produces a simpler star shape.


Inner Radius

Defines the distance from the center of the star to the inner vertices (the recessed points between the spikes).

Changing this value controls how deep the inner part of the star appears.


Outer Radius

Defines the distance from the center of the star to the outer vertices (the tips of the spikes).

Increasing the outer radius makes the star larger.


Inner Roundness

Controls the roundness of the inner corners of the star.

0% produces sharp inner points


Higher values create smoother, rounded inner curves




Outer Roundness

Controls the roundness of the outer tips of the star.

0% produces sharp spikes


Higher values round the tips of the star




Angle

Defines the rotation angle of the star.

Changing this value rotates the star around its center.
