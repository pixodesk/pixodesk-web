# Repeater Tool

The Repeater Tool allows you to create multiple, synchronized instances of an object with a single click. You can create complex patterns, radial symmetries, and geometric arrays that remain fully editable.

## How to Create a Repeater

1. Select the shape you want to repeat.

2. Group the shape using **Object → Group** or `Ctrl/Cmd + G`.

3. Enable the Repeater by ticking the **Repeater** checkbox in the Properties Panel.

By creating copies this way, you can:

- Modify shape and repeater properties independently, giving you more creative control.
- Reflect all changes made to the original shape across all repeater copies instantly.
- Add multiple shapes to the group to repeat them together as a single unit.

## Repeater Properties

Once a Repeater is applied, you can modify the following properties:

### Copies

Determines the total number of instances generated.

### Origin

Sets the pivot point or center of the transformation.

### Translation

Controls the distance and direction between each copy (e.g., moving each copy 20px to the right).

### Rotation

Determines the angle of each subsequent copy.

### Scale

Adjusts the size of each copy relative to the previous one.

## Presets and Controls (Top Panel)

When a Repeater is active, the Top Panel provides quick-access presets and management options:

- **Circle Preset** — instantly arranges copies in a perfect radial array.
- **Line Preset** — arranges copies in a straight path.
- **Add (+)** — adds one more copy to the sequence.
- **Remove (-)** — removes one copy from the sequence.
- **Cancel Repeater** — removes the Repeater effect from the group.
