# Repeater Tool

The Repeater Tool allows you to create multiple, synchronized instances of an object with a single click. You can create complex patterns, radial symmetries, and geometric arrays that remain fully editable.

To create multiple copies:

Select the shape you want to add a Repeater to.

Group the shape and select the Repeater Tool from the Toolbar.

Enable the Repeater by ticking the checkbox in the Property Panel.

By creating copies this way, you can:

Modify shape and repeater properties independently, giving you more creative control.

Reflect all changes made to the original shape across all repeater copies instantly.

Add multiple shapes to the group to repeat them together as a single unit.





Repeater Properties 

Once a Repeater is applied, you can modify the following properties:

Copies: Determines the total number of instances generated.

Origin: Sets the "pivot point" or center of the transformation. 

Translation: Controls the distance and direction between each copy (e.g., moving each copy 20px to the right).

Rotation: Determines the angle of each subsequent copy.

Scale: Adjusts the size of each copy relative to the previous one.



Presets and Controls (Top Panel)

To speed up your workflow, the Top Panel provides quick-access presets and management options:

Circle Preset: Instantly arranges your copies in a perfect radial array.

Line Preset: Arranges copies in a straight path.

Add (+): Adds one more element to the current sequence.

Remove (-): Subtracts one element from the sequence.

Cancel Repeater: Removes the Repeater effect
