# Spray

The Spray Tool allows you to add multiple instances of an object across your canvas with organic, randomized distribution.

## Technical Efficiency

The Spray Tool is highly optimized for performance. It creates SVG `<use>` elements, which are essentially clones that reference a single original shape. This keeps your file size small and rendering speed fast, even with hundreds of copies on the canvas.

## How to Create the Spray Effect

1. Select the shape you wish to spray.

2. Group the shape using `Ctrl/Cmd + G`.

3. Select the Spray Tool from the Toolbar.

4. Click or drag on the canvas to distribute copies.

### Why the Group Workflow is Better

- **Global Updates** — modify the original shape inside the group and every sprayed instance updates instantly.
- **Multi-Shape Sprays** — add multiple shapes into the group. The Spray Tool treats them as a single unit, letting you spray complex clusters at once.

## Spray Properties

You can customize the behavior and randomness of the Spray Tool through the following settings:

### Spray Radius

Controls the width of the spray area. A larger radius spreads shapes over a wider surface.

### Spray Amount

Determines the density of the spray — how many copies are generated per click or drag.

### Spray Rotation

Adds a random rotation to each copy, making the distribution look more natural.

### Spray Minimum / Maximum Scale

Sets a size range for the copies. The tool randomly picks a size between these two values to create depth.

### Spray Minimum / Maximum Opacity

Sets a transparency range for the copies. Useful for creating fading effects or atmospheric elements like clouds or dust.
