# Align and Distribute Nodes
Selected nodes can be aligned relative to each other.
Available alignment options include:
Align Nodes Left


Align Nodes Center


Align Nodes Right


Align Nodes Top


Align Nodes Middle


Align Nodes Bottom



Node Distribution
You can distribute nodes evenly across the selected range.
Available distribution options include:
Distribute Nodes Horizontally


Distribute Nodes Vertically


These commands evenly space nodes along the selected axis.

Keyboard Shortcuts and Modifiers
The Node Tool supports several useful keyboard shortcuts and modifiers.
Double-click a control handle
 Removes the control handle from the node, converting it into a sharp corner node.
Shift (while dragging nodes)
 Constrains node movement to horizontal or vertical directions (90°).
This helps maintain precise alignment when editing paths.
