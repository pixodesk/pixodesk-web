# Align and Distribute Nodes

Selected nodes can be aligned and distributed relative to each other using commands from the **Path** menu.

## Align Nodes

Available alignment options:

- **Align Nodes Left** — aligns all selected nodes to the leftmost node
- **Align Nodes Center** — aligns all selected nodes to the horizontal center
- **Align Nodes Right** — aligns all selected nodes to the rightmost node
- **Align Nodes Top** — aligns all selected nodes to the topmost node
- **Align Nodes Middle** — aligns all selected nodes to the vertical center
- **Align Nodes Bottom** — aligns all selected nodes to the bottommost node

## Distribute Nodes

You can distribute nodes evenly across the selected range:

- **Distribute Nodes Horizontally** — evenly spaces nodes along the horizontal axis
- **Distribute Nodes Vertically** — evenly spaces nodes along the vertical axis

## Keyboard Shortcuts and Modifiers

### Double-click a control handle

Removes the control handle from the node, converting it into a sharp corner node.

### Shift (while dragging nodes)

Constrains node movement to horizontal or vertical directions (90°). This helps maintain precise alignment when editing paths.
