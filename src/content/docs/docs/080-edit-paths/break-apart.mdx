# Break Apart

`Shift+Alt+K`

Separates a compound path into individual independent paths. Each resulting shape can then be edited separately.

## How to Use

1. Select a compound path.
2. Choose **Path → Break Apart** or press `Shift+Alt+K`.

This is the reverse of [Combine Paths](/docs/combine-paths).
