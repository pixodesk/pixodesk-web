# Mirror Path

The Mirror Path operation allows you to quickly create symmetrical shapes from an open path.

## How to Use

1. Draw half of the desired shape using the Pen Tool.

2. With the Node Tool, select the two open end nodes of the path.

3. Apply **Path → Mirror Path**.

The path is mirrored to the opposite side, creating a perfectly symmetrical full shape.

This technique is useful for creating icons, logos, and other symmetrical illustrations while drawing only half of the design.
