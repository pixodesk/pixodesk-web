# Node Tool

The Node Tool allows you to edit and refine vector paths by modifying nodes (points) and path segments. With this tool you can reshape paths, adjust curves, add or remove nodes, and control the direction of path segments.

Select the Node Tool from the Toolbar Panel, then click a path on the canvas to reveal its nodes and control handles.

When nodes are selected, additional editing options become available through the context menu and the Top Panel.
