# Reverse Path

Reverses the direction of the path (the order in which nodes are traversed).

This may affect animations, strokes with markers, or path-based effects that depend on path direction.

## How to Use

Select a path, then choose **Path → Reverse Path**.

To set the starting node of a path instead of reversing it entirely, use **Path → Path Start** after selecting the desired node with the Node Tool.
