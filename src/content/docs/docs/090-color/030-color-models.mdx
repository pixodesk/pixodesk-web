# Color Models

Colors can be defined using two color models. Toggle between them using the switch above the numeric inputs.

## RGBA

Defines colors using Red, Green, Blue, and Alpha (transparency) values. Each channel ranges from 0 to 255, and Alpha from 0% to 100%.

## HSLA

Defines colors using Hue (0–360°), Saturation (0–100%), Lightness (0–100%), and Alpha values.

## HEX

Colors can also be entered directly as a hexadecimal value in the HEX input field (e.g. `#d41a1a`).

## Alpha

The Alpha channel controls the transparency of the color and is available in both RGBA and HSLA modes.
