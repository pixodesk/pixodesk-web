# Fill

Fill controls the interior color of a shape. To choose a fill color, you can:

- Select a color from the color picker
- Enter a HEX color value in the input field
- Adjust individual RGBA color values
- Adjust individual HSLA color values

## Fill Opacity

Controls the transparency of the fill color. Lower values make the fill more transparent; 100% keeps the fill fully visible.

## Fill Rule

Defines how the interior of complex or self-intersecting paths is determined when applying a fill.

### Nonzero

The default rule. Determines the filled region based on the direction of path segments. Areas where the path winding count is not zero are filled.

### Even-Odd

Determines the filled region by counting how many times a line drawn from a point crosses the path. If the number of crossings is odd, the area is filled; if it is even, the area remains empty.

This rule is useful for creating shapes with holes or cut-out regions inside overlapping paths.
