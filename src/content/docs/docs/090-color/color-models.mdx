# Color Models

Colors can be defined using two color models:

RGBA

Defines colors using Red, Green, Blue, and Alpha (transparency) values.

HSLA

Defines colors using Hue, Saturation, Lightness, and Alpha values.

The Alpha channel controls the transparency of the color.

Recently used colors on the canvas appear below the color picker. Clicking one of these colors allows you to quickly apply the same color to other shapes.
