# Color Panel

The Color Panel allows you to control the visual appearance of shapes using Fill, Stroke, Gradients, Patterns, and Opacity.

You can apply colors to individual layers, groups of layers, or the entire SVG document. Colors are applied according to standard SVG inheritance rules, allowing parent groups to control the appearance of child elements.

The Color Panel provides several color types and editing tools.
