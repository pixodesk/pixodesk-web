# Color Types

The Fill option controls the interior color of a shape.

The Stroke option controls the outline of a shape.

For Fill and Stroke, one of the following color types can be used:

No Color

Removes the fill or stroke from the object.

Flat Color

Applies a single solid color.

Linear Gradient

Applies a gradient that transitions between colors along a straight line.

Gradient direction, scale, and position can be adjusted using gradient controls.

Circular Gradient

Applies a radial gradient that spreads outward from a central point.

You can control the center, radius, and focal point of the gradient.

Pattern

Applies a repeating pattern using a tiled design.

Pattern parameters such as translation, rotation, and scale can be adjusted.

Unset Color

Removes the color definition from the current element so that it inherits color from its parent group.

This feature is useful for applying a single color to multiple shapes through group styling.
