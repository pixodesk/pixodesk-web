# Edit Used Colors


The Used Colors section shows colors currently used in the document.

Clicking a color instantly applies it to the selected object.

This helps maintain color consistency across the design.



You can modify shared colors across the entire document.

This allows you to update color themes instantly.

To edit shared colors:

Open the Edit Color Panel located under the Layer Tree.





Select the color you want to change across all shapes.





Choose a new color from the Color Wheel or from the Used Colors list.





The new color will immediately replace the previous color in all shapes and layers that use it.

This feature makes it easy to experiment with different color palettes and themes.
