# Edit Used Colors

The **Used Colors** section shows all colors currently used in the document. Clicking a color swatch instantly applies it to the selected object, helping maintain color consistency across the design.

## Editing Shared Colors

You can replace a color across the entire document at once. This allows you to update color themes instantly without editing each shape individually.

To edit a shared color:

1. Open the **Edit Color Panel** located under the Layer Tree.
2. Select the color you want to change across all shapes.
3. Choose a new color from the Color Wheel or from the Used Colors list.

The new color immediately replaces the previous color in all shapes and layers that use it.
