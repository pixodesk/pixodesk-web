# Eyedropper

The Eyedropper Tool allows you to sample colors directly from objects on the canvas.

## How to Use

1. Select the object you want to apply a color to.
2. Select the Eyedropper Tool from the Toolbar.
3. Click any element on the canvas to copy its fill or stroke color.

The sampled color is applied to the selected object's active color slot (Fill or Stroke, whichever is currently selected in the Color Panel).
