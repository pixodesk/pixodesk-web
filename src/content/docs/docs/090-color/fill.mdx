# Fill

To choose a fill color for a shape, you can:

select a color from the color picker

enter a HEX color value in the input field

adjust individual RGBA color values

adjust individual HSLA color values

Additional Fill settings in the Properties Panel include the following options:

Fill Opacity

Controls the transparency of the fill color. Lower values make the fill more transparent, while 100% keeps the fill fully visible.

Fill Rule

Defines how the interior of complex or self-intersecting paths is determined when applying a fill. The fill rule controls which areas of the shape are considered inside the path and should be filled.

Two fill rules are available:

Nonzero

This is the default rule. It determines the filled region based on the direction of path segments. Areas where the path winding count is not zero are filled.

Even-Odd

Determines the filled region by counting how many times a line drawn from a point crosses the path. If the number of crossings is odd, the area is filled; if it is even, the area remains empty.

This rule is useful for creating shapes with holes or cut-out regions inside overlapping paths.
