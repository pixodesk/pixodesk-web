# Gradients

Gradients allow smooth transitions between multiple colors. You can add multiple gradient points with different colors and opacity.

To choose a gradient color for each gradient point for a shape, you can:

select a color from the color picker 

enter a HEX color value in the input field 

adjust individual RGBA color values

adjust individual HSLA color values

To adjust length between gradient stop colors choose Gradient tool from Toolbox Panel and change the position of gradient points. You can change the gradient direction by pulling gradient end line points on the canvas. 



To jump between gradient points using angle brackets next to the color line ( < > select previous, select next ) or delete selected color by pressing the bin icon next to select square brackets.

You can edit gradient parameters directly in the Edit Gradient section.







Linear Gradient Options

Start / End

Defines the gradient direction.

Position

Moves the gradient within the object.

Rotation

Rotates the gradient axis.

Scale

Controls gradient stretching.





Radial Gradient Options

Center

Defines the origin point of the gradient.

Radius

Controls the size of the gradient circle.

Focal Point

Moves the brightest point inside the gradient.



Gradient Units

Defines how gradient coordinates are calculated.

objectBoundingBox

The gradient is calculated relative to the shape's bounding box.

userSpaceOnUse

The gradient uses the document coordinate system.





Spread Method

Defines how gradients behave outside their defined range.

pad - extends the outermost color

reflect - mirrors the gradient pattern

repeat - repeats the gradient
