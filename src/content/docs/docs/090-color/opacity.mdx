# Opacity

Opacity controls the transparency of colors and layers.

## Color Opacity

For flat colors and gradient stops, opacity is adjusted using the **Alpha (A)** slider below the color picker. A value of 100% is fully opaque; 0% is fully transparent.

## Layer Opacity

For pattern fills, opacity should be applied at the layer level in the **Appearance** section of the Properties Panel, rather than through the color Alpha channel.
