# Opacity

Opacity controls the transparency of colors.

Color Opacity

For flat colors and gradient stops, opacity can be adjusted using the Alpha slider under the color picker.

Layer Opacity

For pattern fills, opacity should be applied at the layer level in the Appearance section of the Properties Panel.
