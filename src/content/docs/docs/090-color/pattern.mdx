# Patterns

Patterns allow shapes to be filled with repeating graphics.

## Applying a Pattern

Choose a pattern from the preset list in the Color Panel. You can also modify patterns using one of two methods:

- In the **Pattern** section in the Properties Panel (below the preset list)
- By double-clicking the pattern in the **Pattern Panel** under the Layer Tree

## Pattern Settings

### Pattern Fill / Stroke

Defines the color used for pattern tiles.

### Translation

Moves the pattern within the shape.

### Rotation

Rotates the pattern tiles.

### Scale

Resizes the pattern.

### Tile Start / Tile Size

Defines the pattern grid — the origin point and dimensions of each repeating tile.

Patterns repeat automatically to fill the entire shape area.
