# Patterns

Patterns allow shapes to be filled with repeating graphics.

You can choose the pattern from the present list and modify it with two methods:

in the Pattern section in the Properties menu (under pattern preset list) or 

by choosing the pattern with double click in the Pattern Panel under the Layer Tree.

Pattern settings in Properties Menu include:

Pattern Fill / Stroke

Defines the color used for pattern tiles.

Translation

Moves the pattern within the shape.

Rotation

Rotates the pattern tiles.

Scale

Resizes the pattern.

Tile Start / Tile Size

Defines the pattern grid.

Patterns repeat automatically to fill the entire shape area.
