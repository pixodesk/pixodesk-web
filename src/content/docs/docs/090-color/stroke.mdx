# Stroke

To choose a stroke color for a shape, you can:

select a color from the color picker

enter a HEX color value in the input field

adjust individual RGBA color values

adjust individual HSLA color values



Additional Stroke settings in the Properties Panel include:





Stroke Width

Defines the thickness of the outline.

Line Cap

Controls how the ends of open paths appear.

Line Join

Controls how corners between path segments are rendered.

Dash Array

Creates dashed or dotted stroke patterns. Multiple dash–gap values can be added to create complex dash patterns.

Dash Offset

Adjusts the starting position of the dash pattern along the path.

Cap and Join

The appearance of dashed strokes can also be modified by choosing different Cap and Join styles.

Cap:

Butt


Round


Square


Join:
Miter


Round


Bevel
