# Unset Colors

Unset Color removes the color definition from a specific element.

This allows colors to be controlled by a parent group layer.

For example, multiple shapes inside a group can use unset colors, while the group itself defines the fill or stroke color. Changing the color on the group will automatically update all shapes inside it.

This makes it easy to update colors across complex illustrations.
