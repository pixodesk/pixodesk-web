# Unset Color

Unset Color removes the color definition from a specific element, allowing it to inherit color from its parent group layer.

## How It Works

For example, multiple shapes inside a group can have their fill or stroke set to Unset. The group itself then defines the fill or stroke color. Changing the color on the group automatically updates all shapes inside it.

This makes it easy to update colors across complex illustrations without editing each shape individually.
