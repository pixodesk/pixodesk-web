Align and Distribute Objects


Aligning Objects
You can align objects using:
Object > Align menu


Alignment controls in the Top Panel (when Selection or Transform tool is active)


Alignment options in the Properties Panel (when the Arrange action is enabled)


Alignment Options
What to align:
Each Selected Shape - aligns each object individually


All Selection - treats the selection as a group


Align relative to:
Page


All Shapes


Selected Shapes


Axis Origin


Horizontal Alignment
Left - aligns objects to the left edge


Center - aligns objects to the horizontal center


Right - aligns objects to the right edge


Vertical Alignment
Top - aligns objects to the top edge


Middle - aligns objects to the vertical center


Bottom - aligns objects to the bottom edge



Distributing Objects
You can distribute objects using:
Object > Distribute menu


Distribution controls in the Top Panel (available when two or more objects are selected)


Distribution options in the Properties Panel (when the Arrange action is enabled)


Distribution Options
Distribute horizontally:
Left Edges - distributes based on left edges


Centers - distributes based on horizontal centers


Right Edges - distributes based on right edges


Gaps - creates equal spacing between objects


Side by Side - places objects next to each other without gaps


Distribute vertically:
Top Edges - distributes based on top edges


Centers - distributes based on vertical centers


Bottom Edges - distributes based on bottom edges


Gaps - creates equal vertical spacing


Side by Side - stacks objects without gaps


Grid Distribution
Arrange objects into a grid layout with the following options:
Grid Size - defines number of columns and rows


Gaps - sets horizontal and vertical spacing between items


Align - controls how objects are aligned within each grid cell


Distribute Along Last Path
Distributes selected objects along a path.
Auto-rotate - rotates objects to follow the direction of the path


Note:
 The path used for distribution must be placed below the distributed objects in the Layer Tree Panel.
