# Align Origin (Anchor Point)

The origin is the anchor point used as the reference for transformations such as scaling, rotation, and positioning.

## How to Access

You can set the anchor point from several places:

- **Object → Transform → Align Anchor Point** (menu)
- The **Align Origin** button (nine-dot grid icon) in the Top Panel, available when the Selection or Transform Tool is active
- The **Align Origin** button in the Properties Panel → Transform section, next to the Origin input fields

## Anchor Point Positions

You can choose from nine predefined positions relative to the object's bounding box:

- **Top Left, Top Center, Top Right**
- **Middle Left, Center, Middle Right**
- **Bottom Left, Bottom Center, Bottom Right**

The selected position determines the reference point for all transformations. For example, scaling from Top Left keeps that corner fixed while the object grows or shrinks relative to it.
