# Align Origin (Anchor Point)

The Align Origin feature defines the anchor point used for transformations such as scaling, rotation, and positioning.
You can access this feature in several ways:
Choose Object > Transform > Align Anchor Point


Click the Align Origin icon in the Top Panel (available when the Selection or Transform tool is active)


Click the Align Origin icon in the Properties Panel → Transform section, next to the origin input fields


Anchor Point Options
You can choose from nine predefined anchor positions:
Top Left, Top, Top Right


Left, Center, Right


Bottom Left, Bottom, Bottom Right


The selected anchor point defines the reference used during transformations. For example, scaling from Top Left keeps that corner fixed while the object transforms relative to it.
