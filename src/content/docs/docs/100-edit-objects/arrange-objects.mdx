# Arrange Objects

Objects are rendered on the canvas according to their order in the Layer Tree Panel. Items higher in the list appear above those below them.
To change the stacking order of objects, you can:
Use Object > Arrange menu commands


Click Bring to Front or Send to Back icons in the Top Panel (available when the Selection or Transform tool is active)


Use keyboard shortcuts: Shift + Cmd/Ctrl + ] (bring forward) or Shift + Cmd/Ctrl + [ (send backward)


Drag and reorder objects directly in the Layer Tree Panel
