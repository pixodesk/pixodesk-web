# Arrange Objects

Objects are rendered on the canvas according to their order in the Layer Tree Panel. Items higher in the list appear in front of those below them.

## Changing Stacking Order

To change the stacking order of a selected object, you can:

- Use **Object → Arrange** menu commands
- Click **Bring to Front** or **Send to Back** icons in the Top Panel (available when the Selection or Transform Tool is active)
- Use keyboard shortcuts:
  - `Ctrl/Cmd + Shift + ]` — Bring to Front
  - `Ctrl/Cmd + Shift + [` — Send to Back
- Drag and reorder objects directly in the Layer Tree Panel
