# Duplicate

To duplicate selected objects, you can:

- Choose **Edit → Duplicate** from the menu
- Press `Cmd/Ctrl + D`
- Use standard copy (`Cmd/Ctrl + C`) and paste (`Cmd/Ctrl + V`) commands

Duplicated objects are placed directly on top of the originals. You can then drag them to a new position.
