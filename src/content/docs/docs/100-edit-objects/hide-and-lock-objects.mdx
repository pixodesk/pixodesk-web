# Hide and Lock Objects
You can control the visibility of objects in your document using the Object Tree Panel. Click the eye icon next to an object to toggle its visibility on or off.
To avoid unintended changes, objects can be locked. Click the lock icon to lock or unlock an object. Locked objects cannot be selected or modified directly on the canvas, but they remain accessible and selectable from the Object Tree Panel.
