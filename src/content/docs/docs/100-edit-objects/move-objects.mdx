# Move Objects

Objects can be moved on the canvas using the mouse, keyboard arrow keys, or by entering numeric values in the Properties Panel.

## Moving with the Mouse

Select an object with the Selection Tool, then click and drag it to a new position.

### Constrain to 90°

Hold **Shift** while dragging to constrain movement to horizontal or vertical directions only. This prevents accidental diagonal movement and is useful for keeping objects aligned on an axis.

## Moving with Arrow Keys

With an object selected, use the arrow keys to nudge it one pixel at a time:

- **← → ↑ ↓** — move 1 px in the arrow direction
- **Shift + arrow key** — move in larger increments (10 px)

## Moving with Numeric Input

For precise positioning, enter exact X and Y coordinates in the **Position** fields in the **Transform** section of the Properties Panel.

## Moving Objects Within a Group

To move an individual object inside a group without ungrouping:

1. Hold **Cmd/Ctrl** and click the object directly on the canvas to select it within the group.
2. Drag or use arrow keys to reposition it independently.
