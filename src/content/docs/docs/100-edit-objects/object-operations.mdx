# Object Operations

Boolean operations such as **Unite**, **Subtract**, **Intersect**, and **Exclude**, as well as **Combine**, **Break Apart**, **Stroke to Path**, and **Convert to Bezier Path**, are **path operations** in Pixodesk.

They are accessed via the **Path** menu or the **Path** section of the Properties Panel — not the Object menu.

This is consistent with how professional vector tools (Inkscape, Affinity Designer, Adobe Illustrator) categorise these operations: they act on the geometric path data of shapes, not on object-level properties.

Full documentation for these operations is in the [Path Operations](/docs/path-operations) section:

- [Path Operations](/docs/path-operations) — Unite, Subtract, Intersect, Exclude, Stroke to Path, Convert to Bezier Path
- [Combine Paths](/docs/combine-paths) — join multiple paths into a compound path
- [Break Apart](/docs/break-apart) — split a compound path into individual paths
