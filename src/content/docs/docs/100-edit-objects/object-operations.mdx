# Object Operations
Object operations allow you to combine, modify, and convert shapes into new forms. These operations are available when two or more compatible objects are selected.
You can access object operations from the Object menu, context menu, or related controls in the interface.
Boolean Operations
These operations combine multiple shapes into a single result:
Unite
 Merges selected objects into one shape, combining all areas into a single path.


Subtract
 Removes the top object(s) from the bottom object, cutting out overlapping areas.


Intersect
 Keeps only the overlapping area between selected objects and removes everything else.


Exclude
 Removes overlapping areas and keeps only the non-overlapping parts of the shapes.


Combine
 Joins multiple paths into a single compound path while preserving individual subpaths.



Path Operations
These operations modify the structure of paths:
Break Apart
 Splits a compound shape or combined paths into separate individual shapes or paths.


Stroke to Path
 Converts the stroke of an object into a filled path, allowing further editing as a shape.
