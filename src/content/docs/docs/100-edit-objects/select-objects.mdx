# Select Objects
Click on an object to select it. To select multiple objects, hold Shift and click additional items, or drag a selection box across the canvas.
In the Layer Tree Panel:
Hold Shift to select a range of adjacent layers


Hold Cmd/Ctrl to select multiple non-adjacent layers


To select an individual object within a group directly on the canvas, hold Cmd/Ctrl and click the object. Once selected, you can move or transform it independently from the group.
