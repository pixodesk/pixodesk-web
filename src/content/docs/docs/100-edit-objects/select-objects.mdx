# Select Objects

Click an object on the canvas to select it. A selection box with handles appears around the selected object.

## Selecting Multiple Objects

- **Shift + Click** — add or remove individual objects from the selection
- **Click and drag** — draw a rubber-band box to select all objects within the area

## Selecting in the Layer Tree

- **Shift + Click** — selects a continuous range of adjacent layers
- **Cmd/Ctrl + Click** — selects multiple non-adjacent layers

## Selecting Inside a Group

To select an individual object within a group directly on the canvas, hold **Cmd/Ctrl** and click the object. Once selected, you can move or transform it independently from the group.
