# Converting Symbols to Objects

You can break the link between a symbol instance and its definition, converting it back into regular editable objects.

## How to Convert

1. Select the symbol instance in the Layer Tree or on the canvas.
2. Use one of:
   - **Object → Replace Link with its Referenced Content** from the menu
   - The corresponding icon in the Top Panel (available when the Selection or Transform Tool is active)

The instance is replaced with a standalone copy of the symbol's contents. It is no longer linked to the symbol definition and will not update when the symbol is edited.
