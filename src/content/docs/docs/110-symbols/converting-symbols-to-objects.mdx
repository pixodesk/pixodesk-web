Converting Symbol to Object
To break the connection between a symbol and its instances:
Select the symbol instance in the Object Tree


Use:


Object > Replace Link with its Referenced Content


Click the corresponding icon in the Top Panel (available when the Selection or Transform tool is active)


This converts the symbol instance back into regular editable objects.
