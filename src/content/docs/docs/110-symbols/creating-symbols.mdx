# Creating Symbols

## How to Create a Symbol

1. Select one or more objects on the canvas.
2. Convert them to a symbol using one of:
   - **Object → Make Symbol** from the menu (`Ctrl/Cmd + P`)
   - The **Make Symbol** button in the Top Panel (available when the Selection or Transform Tool is active)

## What Happens After Creation

- The selected object is replaced by a symbol instance (`<use>` layer) in the Layer Tree
- The original definition is stored in the **Symbols** section of the Objects Panel
- The instance on the canvas looks and behaves the same as the original object

From this point, you can drag additional instances of the symbol from the Symbols panel onto the canvas, and all instances will stay in sync with the definition.
