Editing a Symbol
To modify a symbol:
Open the Symbols section in the Objects Panel


Double-click the symbol


This opens the Symbol View, where you can:
Select shapes or objects you want to edit (in the Symbols Object Tree or directly on the canvas)
Edit the symbol directly on the canvas


Adjust its properties in the Properties Panel


To return to the main document view, click the (...) (three dots) on the top of the Symbols Objects Tree.
Note:
 Any changes made to a symbol are automatically applied to all its instances.
