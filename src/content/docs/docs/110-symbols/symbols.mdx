Symbols
Shapes, text, paths, and groups can be converted into Symbols and reused across your design. Symbols are represented as <use /> elements, meaning multiple instances reference a single original definition.
Using symbols helps:
Reduce file size and optimize animation output 
Maintain consistency across repeated elements
Apply updates globally - editing one symbol updates all its instances

Notes
Symbols are reusable and linked - editing one updates all instances
They are especially useful for repeated elements and animation optimization
Only unused symbols can be deleted from the Symbols section
Symbol instances appear as <use /> layers in the Object Tree
