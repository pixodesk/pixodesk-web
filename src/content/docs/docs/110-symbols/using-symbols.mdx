Using Symbols
You can place multiple instances of the same symbol on the canvas in two ways:
Drag and Drop
Open the Symbols section in the Objects Panel


Select a symbol using its preview


Drag and drop it onto the canvas


Duplicate Existing Instance
Select a symbol instance in the Object Tree


Duplicate it using:


Edit > Duplicate or Cmd/Ctrl + D


Standard copy and paste commands


All instances remain linked to the original symbol.
