# Creating Markers

## How to Create a Marker

1. Select one or more objects on the canvas.
2. Convert them to a marker using one of:
   - **Object → Make Marker** from the menu
   - The **Make Marker** button in the Top Panel (available when the Selection or Transform Tool is active)

## What Happens After Creation

- The selected object is removed from the canvas and stored as a marker definition
- The marker appears in the **Markers** section of the Objects Panel with a preview thumbnail, labeled **Unused**

From this point, you can apply the marker to paths from the Properties Panel.
