Editing a Marker
To edit a marker:
Open the Markers section in the Objects Panel


Double-click a marker


This opens the Marker View, where you can:
Select shapes or objects you want to edit (in the Markers Object Tree or directly on the canvas)
Edit the marker directly on the canvas


Adjust its properties in the Properties Panel


To return to the main document, click the (...) (three dots) at the top of the Markers Objects Tree.
Note:
 Changes made to a marker are automatically applied to all paths using it.
