# Markers

Markers are reusable graphic elements that can be attached to the start, middle, and end of a path. They are defined once and referenced multiple times, so adding the same marker to many paths does not increase file size.

## Where Markers Appear

Markers are applied to paths at three positions:

- **Start Marker** (`marker-start`) — appears at the beginning of the path
- **Mid Marker** (`marker-mid`) — appears at each intermediate node along the path
- **End Marker** (`marker-end`) — appears at the end of the path

Each position can use a different marker, or all three can use the same one.

## Common Uses

- Arrows and line endings
- Dashed or decorative paths
- Diagrams, charts, and technical illustrations
- Motion graphics where repeated elements follow a path

## Notes

- Markers are linked — editing a marker definition updates all paths that reference it
- Adding more nodes to a path automatically adds more Mid Marker instances
- Only unused markers (those not applied to any path) can be deleted
- In SVG, markers are stored inside `<defs>` and referenced via `marker-start`, `marker-mid`, and `marker-end` attributes
