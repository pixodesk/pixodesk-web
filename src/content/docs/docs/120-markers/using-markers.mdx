Using Markers
Markers can be applied to a path in three positions:
Start Marker – appears at the beginning of the path


Mid Marker – appears at each node along the path


End Marker – appears at the end of the path


If a Mid Marker is applied, adding more nodes to the path will automatically add more marker instances.
You can assign different markers for each position.
Adding a Marker to a Path
Select a path layer in the Objects Panel


In the Properties Panel, locate Start Marker, Mid Marker, and End Marker options


Choose a marker from the dropdown (custom or preset)


To ensure marker controls are visible:
Enable “Show Stroke Marker options for selected shapes or group object” in the Properties Sections Bar


Note:
 Markers can only be applied to paths. To use markers on shapes or groups, first convert them to paths using:
Path > Stroke to Path



Duplicating Markers
You can duplicate a marker if you want to create a variation:
Open the Markers section in the Objects Panel


Select a marker


Duplicate it using standard copy and paste commands


A new (unused) marker will appear, which you can modify and apply independently.
