Creating a Pattern
To create a pattern, select one or more objects, then use:
Object > Make Pattern


Click the Make Pattern button in the Top Panel (available when the Selection or Transform tool is active)


After creation:
The object is converted into a pattern definition


The pattern appears in the Patterns section in the Objects Panel
