# Deleting Unused Patterns

Unused patterns — those not applied to any object — can be removed to keep your document clean.

## How to Delete

1. Open the **Patterns** section in the Objects Panel.
2. Locate patterns labeled **Unused** (shown with a red label).
3. Click the **bin icon** next to the pattern to delete it.

Patterns that are still applied to one or more objects cannot be deleted until removed from all objects.
