Editing a Pattern
You can edit patterns in two ways:
Editing from an Object on the Canvas
Select an object on the canvas that uses a pattern


In the Properties Panel → Color section, adjust Pattern and Tile options


Editing from the Patterns Panel
Open the Patterns section in the Objects Panel


Double-click a pattern


This opens the Pattern View, where you can:
Select shapes or objects you want to edit (in the Patterns Object Tree or directly on the canvas)


Edit the pattern directly on the canvas


Adjust its properties in the Properties Panel


To return to the main document, click the (...) (three dots) at the top of the Patterns Object Tree.
Note:
 Changes made to a pattern are automatically applied to all objects using it.
