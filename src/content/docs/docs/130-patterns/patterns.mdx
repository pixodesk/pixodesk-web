Patterns
Shapes, text, paths, and groups can be converted into Patterns and reused as Fill or Stroke across different objects in your design. Patterns are defined once and then referenced multiple times, helping keep file size small and efficient.
Because patterns are reused as references, the same pattern can be applied to multiple objects without duplicating geometry. This makes them especially useful for:
Background textures and decorative fills


Repeating graphic elements (e.g., stripes, dots, grids)


Complex color fills reused across multiple objects


Consistent styling in illustrations and UI elements


Animated fills where the same pattern is reused


Notes
Patterns are reusable and linked — editing one updates all instances


They are ideal for shared fills and strokes across multiple objects


Only unused patterns can be deleted


In SVG, patterns are defined once (inside `<defs>`) and referenced in fill and stroke attributes
