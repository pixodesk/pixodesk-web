# Using Patterns

## Applying a Pattern

Patterns can be applied as the **Fill** or **Stroke** of any object or group:

1. Select a shape, object, or group in the Layer Tree or on the canvas.
2. In the Properties Panel, go to the **Color** section.
3. Choose the **Fill** or **Stroke** tab.
4. Click the **Pattern** color type button.
5. Choose a pattern from the dropdown — custom patterns appear at the top.

To ensure the Color section is visible, enable **Show Color options** in the Properties Sections Bar.

> **Note:** If you apply a pattern to a group, make sure all inner layers have their color set to **Unset** so the pattern is visible through them.

## Pattern Transform Options

When a pattern is applied, the **Pattern** subsection appears in the Properties Panel with these controls:

- **Translation** — offsets the pattern within the object (X and Y)
- **Rotation** — rotates the pattern (in degrees)
- **Scale** — scales the pattern (X and Y, in %)

## Duplicating a Pattern

To create a variation of an existing pattern:

- Open the **Patterns** section in the Objects Panel, select a pattern, and duplicate it using standard copy (`Cmd/Ctrl + C`) and paste (`Cmd/Ctrl + V`).
- Or, when a pattern-filled object is selected, click **Duplicate Pattern** in the Properties Panel Color section.

A new unused pattern appears, which you can edit and apply independently.
