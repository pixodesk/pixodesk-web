Using Patterns
Patterns can be applied to the Fill or Stroke of an object or group:
Select a shape, object, or group in the Objects Panel


In the Properties Panel → Color section, choose Fill or Stroke


Select the Pattern option


Choose a pattern from the dropdown (custom or preset)


Custom patterns appear at the top of the dropdown list.
To ensure the Color section is visible:
Enable “Show Color options” in the Properties Sections Bar


Note:
 If you apply a pattern to a group, make sure that all inner layers have their color set to Unset, so the pattern is visible.

Duplicating Patterns
You can duplicate a pattern to create a variation:
Open the Patterns section in the Objects Panel


Select a pattern


Duplicate it using standard copy and paste commands


If a shape using the pattern is selected on the canvas, you can also click the “Duplicate Pattern” button in the Properties Panel → Color section.
A new (unused) pattern will appear, which you can modify and apply independently.
