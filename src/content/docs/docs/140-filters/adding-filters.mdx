# Adding Filters

SVG filters can be applied to any shape, object, or group.

## How to Add a Filter

1. Select the layer you want to apply a filter to.
2. In the Properties Panel, scroll to the **Filter** section.
3. Click the **Add Filter** button — a dropdown appears with available presets.
4. Choose a preset to apply it.

## Available Filter Presets

- Drop Shadow
- Inner Shadow
- Outline
- Gaussian Blur
- Motion Blur
- Pixelate
- Warp
- Morphology
- Saturate
- Hue Rotate
- Invert
- Brightness
- Contrast
- Opacity
- Posterize

## Reusing Filters

Once a filter is applied, it is stored in the **Filters** section of the Objects Panel. You can apply the same filter to other layers by selecting them and choosing it from the **Add Filter** dropdown — applied filters appear at the top of the list.

Editing a shared filter updates all layers that reference it.

## Multiple Filters

You can apply multiple filters to the same layer. Each appears as a separate entry in the Filter section of the Properties Panel and can be edited or removed independently.
