Adding a Filter
You can add SVG Filters to your shape, object, or group of objects.

Select the layer you want to modify and click the Add Filter button in the Properties panel → Filter section.
 A dropdown will appear with available filter presets.
The available filter presets include:
Drop Shadow


Inner Shadow


Outline


Gaussian Blur


Motion Blur


Pixelate


Warp


Morphology


Saturate


Hue Rotate


Invert


Brightness


Contrast


Opacity


Posterize


Once a filter is applied:
It appears at the top of the dropdown menu for quick reuse.


You can apply the same filter to other layers by selecting it from this top section.


Editing a shared filter will update all layers using it.
