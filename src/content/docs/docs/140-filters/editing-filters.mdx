Editing Filters

Click the triangle icon next to a filter name to expand it.
In the expanded view (middle-right image):
You can see the filter composition graph


It shows:


The sequence of applied SVG filter primitives


How they are connected


You can:


Modify individual primitives in the Properties panel


Drag and reorder primitives to change the visual result



Adding Filter Primitives
Click the plus icon with dropdown to add new filter primitives.
From the rightmost panel in the image, available SVG filter primitives include:
Flood


Turbulence


Image


Blur


Drop Shadow


Color Matrix


Component Transfer


Morphology


Convolve Matrix


Offset


Tile


Combiners:
Blend


Composite


Merge


Advanced effects:
Displacement Map


Specular Lighting


Diffuse Lighting


Point Light


Spot Light


Distant Light


These primitives can be combined and reordered to create custom filter effects.
