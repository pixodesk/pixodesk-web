# Filter Properties

When a filter is applied to an object, it appears as an entry in the **Filter** section of the Properties Panel. Expand the entry to access its properties.

## Filter Region

- **Position** (X, Y) — defines the position of the filter region relative to the object. Controls where the filter effect is rendered; can be used to shift the visible area
- **Size** (X, Y) — sets the dimensions of the filter region. Increase these values to prevent effects like shadows or blurs from being clipped at the edges

Both Position and Size accept a unit (% or px).

## Primitive Units

Determines the coordinate system used for the filter primitives — typically `px`, defining how values like position, size, and offsets are interpreted.

## Shadow-Specific Properties

These appear for shadow-based presets (Drop Shadow, Inner Shadow):

- **Shadow Radius** — controls the blur intensity of the shadow. Higher values produce a softer shadow; lower values produce a sharper edge
- **Offset** (X, Y) — adjusts the horizontal and vertical displacement of the shadow relative to the object
- **Shadow Color** — the color of the shadow
