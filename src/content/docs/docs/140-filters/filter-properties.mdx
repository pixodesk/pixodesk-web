Filter Properties
In the Properties panel, you can modify parameters of the selected filter.
Position (X, Y)
 Defines the position of the filter region relative to the object. This controls where the filter effect is rendered and can be used to shift the visible area of the effect.


Size (Width, Height)
 Sets the dimensions of the filter region. Increasing the size ensures that effects like shadows or blurs are not clipped at the edges.


Primitive Units
 Determines the coordinate system used for the filter primitives. Typically set to pixels, it defines how values like position, size, and offsets are interpreted.


Shadow Radius
 Controls the blur intensity of the shadow. Higher values create a softer, more diffused shadow, while lower values result in a sharper edge.


Offset (X, Y)
 Adjusts the horizontal and vertical displacement of the shadow relative to the original object, allowing you to control the direction and distance of the shadow.


Shadow Color
 Defines the color of the shadow. You can customize it to match your design.
