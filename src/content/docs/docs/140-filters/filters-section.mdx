# Filters Section

The **Filters** section in the Objects Panel lists all filter definitions used in your document.

## Panel Structure

Each filter entry shows:
- The filter name (e.g., "Drop Shadow")
- The number of elements using it

Expand a filter entry to see its SVG filter primitives (e.g., `<feGaussianBlur/>`, `<feOffset/>`, `<feFlood/>`).

## Shared Filters

Filters are defined once and can be shared across multiple objects. When you apply the same filter to several layers, they all reference the same definition — editing it updates all of them.

Only filters with no objects referencing them can be deleted.
