Filter Section in Objects Panel
All filters used in your SVG are listed in the Filter Panel (left-side panels area, next to the Toolbox).
The panel structure includes:
Header: Displays the name “Filter” and the total number of filters in the document


Filter entry:


Filter name


Number of elements using it


Dropdown menu with additional options
