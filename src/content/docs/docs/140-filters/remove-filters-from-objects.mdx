# Remove Filters from Objects

To remove a filter from an object, select the object on the canvas.

In the Properties panel, under the Filter section, select the filter you want to remove and click the bin icon next to its name.

The filter will be removed from the object. If the filter was applied only to this object, it will also be removed from the Filter section in the Objects panel.

If the same filter is used by another object, it will remain available in the Filter section of the Objects panel.
