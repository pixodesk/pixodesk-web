Clipping Path (for Lottie file format only)
A Clipping Path is a precise, vector-based masking technique used to define visible areas or isolate parts of objects.
Creating a Clipping Path
To create a clipping path, select the objects you want to apply it to, then use:
Object > Add Clipping Path


Click the Mask icon > Add Clipping Path in the Top Panel (available when the Selection or Transform tool is active)


How It Works
A vector path defines the visible area of the objects


Only the area inside the clipping path remains visible
