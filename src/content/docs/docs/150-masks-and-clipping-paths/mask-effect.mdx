Mask Effect
A Mask Effect applies masking as a non-destructive effect through the filter/effects system.
Creating a Mask Effect
To create a mask effect, select the objects you want to mask. The lower layer is used as the mask, and it controls the visibility of the layer above it. Then use:
Object > Add Mask Effect
Click the Mask icon > Add Mask Effect in the Top Panel (available when the Selection or Transform tool is active)


How It Works
The top object is visible only within the boundaries of the underlying object
Both layers remain editable and can be transformed or adjusted at any time
