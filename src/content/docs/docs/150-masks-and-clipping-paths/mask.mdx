Mask
A Mask uses one object to define the visible area of another object or group.
The top object acts as the mask, and only the parts of the underlying objects that fall within its shape remain visible.
Creating a Mask
To create a mask, select the objects you want to mask together with the masking shape, then use:
Object > Make Mask


Click the Mask icon > Make Mask in the Top Panel (available when the Selection or Transform tool is active)


How It Works
The masking shape defines the visible region


Objects outside the mask shape are hidden


The mask remains editable and can be transformed or adjusted at any time
