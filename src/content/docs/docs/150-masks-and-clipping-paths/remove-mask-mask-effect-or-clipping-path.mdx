Removing Mask, Mask Effect, or Clipping Path
To remove a masking or clipping operation, select the masked object or group, then use:
Object > Remove Mask
Click the Mask icon > Remove Mask / Remove Clipping Path in the Top Panel (available when the Selection or Transform tool is active)


Removing a mask, mask effect, or clipping path restores the original visibility of the objects.
