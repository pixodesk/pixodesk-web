# Clipping Paths

> This feature is not yet available.

A Clipping Path is a vector-based masking technique that defines the visible area of an object or group. It is for use with the Lottie file format only.

## How to Create a Clipping Path

1. Select the objects you want to apply it to.
2. Use one of:
   - **Object → Clipping and Masks → Add Clipping Path** from the menu
   - The **Mask** button in the Top Panel → **Add Clipping Path** (available when the Selection or Transform Tool is active)

## How It Works

- A vector path defines the visible area
- Only the area inside the clipping path remains visible
