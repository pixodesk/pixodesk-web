# Mask

A Mask uses one object to control the visible area of objects below it. Only the parts of the underlying objects that fall within the masking shape remain visible.

## How to Create a Mask

1. Select the objects you want to mask together with the masking shape.
2. Apply the mask using one of:
   - **Object → Make Mask** from the menu
   - The **Mask** button in the Top Panel → **Make Mask** (available when the Selection or Transform Tool is active)

## How It Works

- The **topmost** selected object acts as the masking shape
- Objects outside the mask shape are hidden
- The mask remains editable — you can transform or adjust it at any time
