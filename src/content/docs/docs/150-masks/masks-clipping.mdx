# Masks and Clipping

Pixodesk provides two ways to control the visibility of objects using other shapes:

- **Mask** — uses an SVG `<mask>` element. The masking shape defines the visible area of the objects below it.
- **Mask Effect** — applies masking as a non-destructive effect. The lower layer controls the visibility of the layer above it.

Both approaches keep all layers editable after creation. See the individual pages for details on how to create and remove each type.
