# Auto Animation

The **Pin Animation State** feature lets you create animations automatically, without manually adding keyframes.

## How It Works

1. Move the playhead to the time position where you want to fix the object's state.
2. Click **Pin Animation State at Frame** `Alt+A` in the timeline toolbar (or enable it as a toggle to keep it active).
3. Move the playhead to a different time position.
4. Modify the object — change its position, scale, color, or any animatable property.
5. A keyframe is created automatically at the new position.

Repeat steps 3–4 to build up the animation across multiple time points.

## Removing Pins

Click **Unpin All** `Alt+Shift+A` to remove all pins and return to manual keyframe mode.
