Pin Animation (Auto-Animation)
The Pin Animation feature allows you to create animations automatically.
Use the Pin button to fix the state of an object at a specific time.
Then:
Move the timeline playhead to a new position


Modify the object (position, scale, etc.)


A new keyframe is created automatically
