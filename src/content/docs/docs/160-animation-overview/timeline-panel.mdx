# Timeline Panel

The Timeline Panel is located at the bottom of the workspace. It is the primary interface for creating and editing keyframe animations.

The panel consists of three areas:

- **Layer List** — lists document layers and their animated properties with per-property navigation and value editing
- **Keyframe Editor** — the visual timeline where keyframes are placed, moved, and organised
- **Chart Panel** — displays animation curves (value, velocity, acceleration) for editing easing

For a full reference of all controls, buttons, and panel sections, see [Timeline Panel](../../docs/timeline-panel) in the Workspace documentation.

## Animation Controls

Key shortcuts for animation playback:

- `Space` — Play / Pause
- `Alt+A` — Pin Animation State at Frame (auto-animation)
- `Alt+Shift+A` — Unpin All

See [Auto Animation](./auto-animation) and [Pin Multiple Animation States](./pin-multiple-animation-states) for how to use the pin feature to build animations quickly.
