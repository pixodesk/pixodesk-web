Timeline Panel
The Timeline Panel is used to create, edit, and control animations using keyframes.
It provides a visual representation of animated properties over time and allows precise control of motion, timing, and easing.

Timeline Structure
The Animation Timeline Panel consists of several main areas:
Top Toolbar (Playback & Controls)
The top section contains controls for navigating and managing the animation:
Play / Pause (Space) – starts or stops playback


Go to Animation Start / End – jumps to the beginning or end of the timeline


Go to Previous / Next Frame – moves frame by frame


Loop Animation – enables continuous playback


Additional options (available from the menu):
Select All Keyframes / Deselect Keyframes


Add / Remove Inner Loop for Selected Keyframes


Flip Selected Keyframes


Show Velocity Mini Charts



Layer & Property List
Located below the toolbar, this section displays:
Layers and groups


Animated properties (Position, Scale, Radius, etc.)


Layer path hierarchy


Each animated property has:
Keyframe indicators


Navigation arrows to jump between keyframes


Input fields for precise value editing


Loop button to open the Inner Loop dialog



Keyframe Editor (Timeline View)
The central area is the Keyframe Editor (also called Timeline View).
This is where you:
View and edit keyframes over time


Adjust animation timing by moving keyframes


Modify animation duration by dragging keyframes


Additional controls include:
Zoom controls for timeline scaling


Frame range controls


Time indicator (playhead) for scrubbing through the animation



Chart Panel (Graph Editor)
The panel on the right displays animation curves (also known as the Graph Editor).
It visualizes how values change over time using:
Velocity charts


Acceleration charts


Features:
View multiple curves when multiple properties are selected


Edit easing by dragging curves or control handles


Toggle between different chart types
