# Keyframes Overview

Keyframes are the building blocks of animation in Pixodesk Animator Studio. Each keyframe records the value of a property — such as position, size, colour, or opacity — at a specific point in time. The animation engine calculates the values between any two keyframes automatically, producing smooth transitions.

## How Keyframes Work

A property has no animation until it has at least two keyframes. The first keyframe sets the starting state; the second sets the ending state. Everything in between is interpolated.

You can have as many keyframes on a property as you need. Each one becomes a fixed point in time that the animation passes through exactly.

## Animated Properties

Almost any property visible in the [Properties Panel](../../docs/properties-panel) can be animated: position, scale, rotation, opacity, fill colour, stroke colour, stroke width, and more. Each animated property gets its own row in the [Timeline Layer List](../../docs/timeline-layers), where its keyframes appear as diamond markers.

To enable animation for a property, click the **Toggle animation** button next to that property in the Properties Panel. Once enabled, any value change you make while the playhead is positioned at a frame is recorded as a keyframe.

## Two Ways to Create Keyframes

Pixodesk Animator Studio offers two workflows for creating keyframes:

**Manual keyframes** — you move the playhead to a specific frame, adjust a property value in the Properties Panel, and the keyframe is recorded at that position.

**Auto-pin (Pin Animation State at Frame)** — press `Alt+A` or click the **Pin** button in the Timeline toolbar. This pins the current state of all animated properties at the current frame, making it easy to set up animation states without touching individual properties one by one. See [Add Keyframes](./add-keyframes) for details.

## The Timeline

Keyframes are visualised and edited in the [Keyframe Timeline](../../docs/keyframe-timeline) — the central area of the [Timeline Panel](../../docs/timeline-panel). The horizontal axis represents time; each animated property has its own horizontal track. The current playhead position is shown as a vertical line across all tracks.

Between any two keyframes, a small easing preview chart shows the interpolation curve applied to that transition. Click the segment to open the [Easing Panel](../../docs/easing-charts#easing-panel) and adjust the curve.
