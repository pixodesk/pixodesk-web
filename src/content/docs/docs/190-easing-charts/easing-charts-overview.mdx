# Easing Charts

Easing controls how a property value changes between two keyframes — whether it moves at constant speed, accelerates into the end, decelerates from the start, or follows a more complex curve.

In Pixodesk Animator Studio, easing is based on **cubic bezier curves**. Every segment between two keyframes has its own curve, which you can view in the [Chart Panel](../020-workspace/easing-charts) and adjust using the Easing Function panel.

## The Chart Panel

The Chart Panel occupies the right section of the [Timeline Panel](../020-workspace/timeline-panel). It shows up to three animation curves simultaneously, each identified by a watermark label:

- **Value** — how the property value changes over time; always visible
- **Velocity** `ƒ′(t)` — the rate of change; toggle on via Chart Panel More (⋮) → **Show Velocity Chart**
- **Acceleration** `ƒ′′(t)` — the second derivative; toggle on via Chart Panel More (⋮) → **Show Acceleration Chart**

See [Editing Curves](./easing-charts-editor) for how to work with the chart directly.

## Easing Segments

Between any two keyframes in the [Keyframe Timeline](../020-workspace/keyframe-timeline), the segment shows a small visual preview of the easing curve applied to that transition.

Clicking a segment does two things at once:

1. Opens the **Easing Function** panel — a floating panel for choosing and adjusting the easing
2. Updates the Chart Panel to show that segment's curve in detail

## Easing Function Panel

The Easing Function panel is a floating, non-blocking panel that appears when you click a keyframe segment. It has two sections side by side:

**Left — curve editor:**
- A live preview of the bezier curve
- Three preview modes selectable from the panel header: **Easing function** (value curve), **ƒ′(t) - velocity**, **ƒ′′(t) - acceleration**
- Draggable control points (**Out** and **In** handles) to shape the curve
- Numeric inputs for precise handle coordinates (outX, outY, inX, inY)

**Right — preset table:**
- A grid of built-in easing presets with mini curve previews
- Rows are easing types; columns are variants (**in**, **out**, **in-out**)
- Three sort tabs: **By Easing**, **By Velocity**, **By Acceleration** — reorder the presets by their curve character

See [Easing Presets](./easing-charts-presets) for the full preset list.
