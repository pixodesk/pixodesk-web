# Add SVG Animation to Your Project

Putting a saved JSON or pre-rendered SVG animation on a web page — plain HTML, React, Vue, Next.js, Nuxt, Astro, React Native.

## Intro

A saved animation is either a **JSON** file for the Pixodesk player or a **pre-rendered SVG**.
The player is documented in its own docs; the pages below say which one to open for your stack.

- JSON needs the player library on the page: `@pixodesk/svg-animator-web`, or the React / Vue /
  React Native wrappers.
- Pre-rendered SVG needs nothing: inline it, reference it with `<img>` (static frame only) or
  `<object>`, or import it with SVGR / vite-svg-loader.
