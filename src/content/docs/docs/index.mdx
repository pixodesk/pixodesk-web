# Pixodesk Docs

**Pixodesk SVG Animator** is a vector drawing and animation editor. You draw on a canvas, animate
with keyframes on a timeline, and save a file that plays on any web page — as a JSON animation
for the Pixodesk player, as a self-contained SVG, or as Lottie. It is also the SVG half of
**Pixodesk Animator Studio**, which adds the Lottie editor.

## Which file should I save?

| Save as | When | Needs on the page |
| :-- | :-- | :-- |
| **JSON (Pixodesk player)** | apps and frameworks; control from code | the small player library |
| **SVG + CSS animation** | plain HTML, CMS, static sites — it just plays | nothing |
| **SVG + CSS + JS triggers** | same, but start on click / hover / scroll | a few embedded lines |
| **SVG + JS animation** | one self-contained file with every feature | embedded in the file |
| **Lottie / .lottie** | existing Lottie pipelines, mobile apps | a Lottie player |

Details and trade-offs: [File formats: which one to save](/docs/save#file-formats-which-one-to-save).
