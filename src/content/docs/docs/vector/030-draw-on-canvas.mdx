# Draw on Canvas

Drawing shapes and paths: rectangles, ellipses, groups, bezier paths, round corners and the preset shapes.

You can draw rectangles using the Rectangle Tool (R) from the Tools Panel.


Click and drag on the canvas to create a rectangle.


### Keyboard modifiers

Shift — constrains the shape to a perfect square


Option (Alt) — draws the rectangle from the center point where you begin dragging


These modifiers can be combined while drawing to control the placement and proportions of the shape.

## Ellipses

You can draw ellipses using the Ellipse Tool (E) from the Tools Panel.

Click and drag on the canvas to create an ellipse.

### Keyboard Modifiers

While drawing, you can use keyboard modifiers to control the shape.

Shift

Constrains the shape to a perfect circle.

Option (Alt)

Draws the ellipse from the center point where you begin dragging.

These modifiers can be combined while drawing to control both the placement and the proportions of the shape.

## Groups

Objects can be grouped to create more complex structures and to organize elements within a document.

Grouping allows multiple objects to behave as a single unit, making it easier to move, transform, and manage them together.

### Group Objects

To group selected objects, choose:

Object → Group

You can also use the keyboard shortcut:

Ctrl + G (Windows)

Cmd + G (macOS)

### Ungroup Objects

To separate objects from a group, choose:

Object → Ungroup

Keyboard shortcut:

Ctrl + Shift + G (Windows)

Cmd + Shift + G (macOS)

Ungrouping restores the objects so they can be edited individually.

## Bezier Paths

Pixodesk Animator Studio uses Bézier paths to create custom vector shapes and curves. Paths consist of nodes (points) connected by segments, which can be straight or curved.

You can create paths using the Pen Tool (P). To edit existing paths and move individual nodes, use the Node Tool (N).



The Pen tool draws lines and curves. Click on the canvas to start a path. After that, each click will add a corner node to the path. Press and drag adds a curved node. Double-clicking ends the path. To create a closed path, click the start node of the path.

The Pen tool can also be used to connect open paths to each other. Select the first path's node and then select the second path's node to create a connecting segment.





### Pen Tool

The Pen Tool allows you to draw precise straight lines and curved paths.

To start drawing, click on the canvas to create the first node of a path. Each additional click adds another node connected by a line segment.

Creating Straight Segments

Click and release on the canvas to create a corner point.

Corner points produce straight line segments and do not include control handles.



### Creating Curved Segments

Click and drag to create a curved node.

The distance you drag determines the length (strength) of the curve.


The direction you drag determines the angle of the curve.


Curved nodes include control handles that define the shape of the Bézier curve.


### Constraining Angles

Hold the Shift key while dragging to constrain lines or control handles to 90-degree angles. This helps maintain precise alignment when creating paths.




### Ending a Path

You can finish drawing a path using one of the following methods:

Double-click on the canvas


Press the Escape key


To create a closed path, click the starting node of the path.


### Connecting Paths

You can connect open paths within a single shape or between multiple shapes.

Closing a single open path

Select the first and last nodes of an open shape and connect them to form a closed shape.

Connecting Two Open Paths

Select the two paths that you want to connect.


Select the Pen Tool.


Click the open node of the first path.


Click the open node of the second path.


A new segment is created, connecting the two paths into a single continuous path.

## Round Corners

Rectangles and other vector shapes can have rounded corners.

You can control corner rounding in the Properties Panel under the Shape section.

### Corner Radius

Defines the radius used to round the corners of the shape.

The lock control allows you to link or unlink the horizontal and vertical radius values:

Locked — both values change proportionally


Unlocked — X and Y radius values can be adjusted independently




### Round Corner Tool

Pixodesk Animator Studio also provides a Round Corner Tool (C) located in the Tools Panel. This tool allows selective rounding of individual corners on vector shapes.

When the Round Corner Tool is active, additional options appear in the Top Panel.

#### Corner Types

You can choose the style of the corner:

Round — smooth circular rounding

Bevel — straight edge cut across the corner

Inverted Round — concave rounded corner

#### Corner Radius

Specifies the rounding radius applied to selected corners.

#### Editing Multiple Corners

You can apply corner settings to multiple corners simultaneously.

Hold Shift to select multiple corners of a shape

Adjust the radius in the Top Panel to apply the same value to all selected corners

You can also copy and paste corner radius values between corners by copying the value from the radius input field and applying it to other selected corners.

#### Editing Corners on the Canvas

Corners can also be edited directly on the canvas.

Drag the corner of the shape to interactively adjust the corner radius until the desired shape is achieved.

## Shape Presets (Stars, Polygons, Spirals)

The **Shape tool** (`W`) draws three preset shapes. With the tool active, pick the sub-type —
**Star**, **Polygon** or **Spiral** — in the toolbar, then click and drag on the canvas. Hold
**Shift** while drawing to constrain the rotation to 30-degree increments, so the shape is
aligned precisely (a star points exactly in the direction you want). After creating the shape,
adjust its appearance in the Properties panel.

Each preset has one geometry property, **Points Count**, whose meaning depends on the sub-type.

### Stars

Select the **Star** sub-type and drag to draw a star.

**Points Count** — the number of points (spikes) that form the star. Increasing the value creates
a star with more points; decreasing it produces a simpler star shape.

### Polygons

Select the **Polygon** sub-type and drag to draw a regular polygon.

**Points Count** — the number of sides (vertices) of the polygon. Increasing the value creates
polygons with more sides; decreasing it produces simpler shapes such as triangles or pentagons.

### Spirals

Select the **Spiral** sub-type and drag to draw a spiral.

**Points Count** — the number of turns in the spiral. Increasing the value adds more rotations,
making the spiral longer and more complex.
