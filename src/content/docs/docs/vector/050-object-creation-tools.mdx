# Object Creation Tools

Tools that build new objects from existing ones: Shape Builder, Repeater and Spray.

## Shape Builder

The Shape Builder Tool is an intuitive and interactive tool designed to simplify the creation of complex shapes. It allows you to merge, delete, and extract overlapping areas of objects directly on the canvas.

Instead of drawing complex curves from scratch, you can build designs by combining simple shapes such as circles and rectangles, and then refine them by merging or removing the overlapping areas.

### How to Use the Shape Builder

To begin using the tool, follow these steps:

1. Select two or more shapes. If nothing is selected, the tool will not have any paths to work with.

2. Select the Shape Builder Tool from the Toolbar.

When the tool is active, a mesh overlay appears over the selected shapes and their intersecting areas. This mesh highlights the regions that can be modified.

### Building the New Shape

#### Manual Selection

Click across multiple intersecting areas to combine them into a single new object.

#### Top Panel Options

You can use the Selection menu in the Top Panel to quickly choose one of the following options:

- **All** — selects all available areas.
- **Subtract** — prepares the tool to remove selected areas.
- **Intersect** — keeps only the areas where shapes overlap.
- **Exclude** — removes overlapping areas and keeps the remaining parts.
- **Deselect** — clears the current selection.

### Basic Commands: Add and Remove

The Shape Builder Tool operates in two primary modes:

#### Add Mode (+)

Combines the selected areas into a single unified shape.

#### Remove Mode (-)

Deletes the highlighted areas from the canvas. This mode is useful for cutting holes or trimming unwanted parts from overlapping shapes.

## Repeater

The Repeater Tool allows you to create multiple, synchronized instances of an object with a single click. You can create complex patterns, radial symmetries, and geometric arrays that remain fully editable.

### How to Create a Repeater

1. Select the shape you want to repeat.

2. Group the shape using **Object → Group** or `Ctrl/Cmd + G`.

3. Enable the Repeater by ticking the **Repeater** checkbox in the Properties Panel.

By creating copies this way, you can:

- Modify shape and repeater properties independently, giving you more creative control.
- Reflect all changes made to the original shape across all repeater copies instantly.
- Add multiple shapes to the group to repeat them together as a single unit.

### Repeater Properties

Once a Repeater is applied, you can modify the following properties:

#### Copies

Determines the total number of instances generated.

#### Origin

Sets the pivot point or center of the transformation.

#### Translation

Controls the distance and direction between each copy (e.g., moving each copy 20px to the right).

#### Rotation

Determines the angle of each subsequent copy.

#### Scale

Adjusts the size of each copy relative to the previous one.

### Presets and Controls (Top Panel)

When a Repeater is active, the Top Panel provides quick-access presets and management options:

- **Circle Preset** — instantly arranges copies in a perfect radial array.
- **Line Preset** — arranges copies in a straight path.
- **Add (+)** — adds one more copy to the sequence.
- **Remove (-)** — removes one copy from the sequence.
- **Cancel Repeater** — removes the Repeater effect from the group.

## Spray

The Spray Tool allows you to add multiple instances of an object across your canvas with organic, randomized distribution.

### Technical Efficiency

The Spray Tool is highly optimized for performance. It creates SVG `<use>` elements, which are essentially clones that reference a single original shape. This keeps your file size small and rendering speed fast, even with hundreds of copies on the canvas.

### How to Create the Spray Effect

1. Select the shape you wish to spray.

2. Group the shape using `Ctrl/Cmd + G`.

3. Select the Spray Tool from the Toolbar.

4. Click or drag on the canvas to distribute copies.

#### Why the Group Workflow is Better

- **Global Updates** — modify the original shape inside the group and every sprayed instance updates instantly.
- **Multi-Shape Sprays** — add multiple shapes into the group. The Spray Tool treats them as a single unit, letting you spray complex clusters at once.

### Spray Properties

You can customize the behavior and randomness of the Spray Tool through the following settings:

#### Spray Radius

Controls the width of the spray area. A larger radius spreads shapes over a wider surface.

#### Spray Amount

Determines the density of the spray — how many copies are generated per click or drag.

#### Spray Rotation

Adds a random rotation to each copy, making the distribution look more natural.

#### Spray Minimum / Maximum Scale

Sets a size range for the copies. The tool randomly picks a size between these two values to create depth.

#### Spray Minimum / Maximum Opacity

Sets a transparency range for the copies. Useful for creating fading effects or atmospheric elements like clouds or dust.
