# Edit Paths

Node editing, path operations, and the commands that combine, break, reverse and mirror paths.

## Node Tool

The Node Tool allows you to edit and refine vector paths by modifying nodes (points) and path segments. With this tool you can reshape paths, adjust curves, add or remove nodes, and control the direction of path segments.

### How to Use the Node Tool

1. Select the Node Tool from the Toolbar Panel.

2. Click a path on the canvas to reveal its nodes and control handles.

3. Click a node to select it. Drag a selected node to reposition it.

4. Click and drag an empty area to draw a selection box and select multiple nodes at once.

When nodes are selected, additional editing options become available in the Top Panel and through the **Path** menu.

### Selecting Nodes

- **Click** a node to select it.
- **Shift + Click** to add or remove individual nodes from the selection.
- **Click and drag** on the canvas to rubber-band select multiple nodes.
- **Ctrl/Cmd + A** to select all nodes on the path.

### Node Handles

Curve nodes display control handles — small lines extending from the node that define the direction and shape of the curve.

- Drag a handle to adjust the curve on that side of the node.
- Double-click a control handle to remove it, converting the node into a sharp corner.

### Animating Path Shapes

The Node Tool works in animation mode too. To animate a path so its shape changes over time, use Pin Animation State to mark a frame, then move nodes — keyframes are created automatically. See [Path Animation](/docs/animation#path-animation) for the full workflow.

## Node Editing Commands

These commands are available from the **Path** menu and the Top Panel when the Node Tool is active.

### Add Node

Adds a new node to the selected path segment.

This allows you to create additional control points for more precise shape editing.

### Remove Node

Deletes the selected node while preserving the overall path shape as much as possible.

### Break at Selected Points

Splits the path at the selected nodes, creating separate path segments.

This is useful when you want to edit parts of a path independently or delete individual path segments.

### Node Type Options

These options change how a node controls the direction of the path.

#### Make Line Corner

Converts the selected node to a corner node with straight line segments.

#### Make Curve Corner

Converts the node to a corner node with curve handles, allowing each side of the curve to be controlled independently.

#### Make Smooth

Creates a smooth transition between path segments by aligning the control handles along the same direction.

#### Make Symmetric

Creates a smooth node where both control handles remain equal in length and direction, producing a balanced curve.

#### Make Asymmetric

Allows the control handles to move independently, giving full control over the curve on each side of the node.

## Path Operations

Path operations allow you to combine or modify multiple shapes to create more complex vector objects.

To use these operations, select at least two objects, then choose the desired command from the **Path** menu.

The selected shapes are processed relative to the backmost object in the selection order.

### Unite

`Alt+U`

Combines all selected objects into a single shape. All overlapping and adjacent areas are merged together to form one continuous path.

### Subtract

`Alt+S`

Removes the areas where the front objects overlap the backmost object. This operation cuts the overlapping shapes out of the back object.

### Intersect

`Alt+I`

Creates a new shape that contains only the areas where the selected objects overlap. All non-overlapping parts are removed.

### Exclude

`Alt+E`

Combines the selected shapes and removes the areas where two or more objects overlap. This produces a compound shape with transparent overlapping regions.

### Stroke to Path

`Alt+P`

Converts the stroke of a shape into a filled path.

This operation transforms the visual stroke into an actual vector shape that can be edited, reshaped, or used in further path operations.

### Convert to Bezier Path

Converts a shape (such as a rectangle, ellipse, or text element) into an editable Bézier path.

Once converted, all anchor points become editable with the Node Tool, giving you full control over the shape's geometry. This is necessary before you can use node-level editing on primitive shapes.

## Align and Distribute Nodes

Selected nodes can be aligned and distributed relative to each other using commands from the **Path** menu.

### Align Nodes

Available alignment options:

- **Align Nodes Left** — aligns all selected nodes to the leftmost node
- **Align Nodes Center** — aligns all selected nodes to the horizontal center
- **Align Nodes Right** — aligns all selected nodes to the rightmost node
- **Align Nodes Top** — aligns all selected nodes to the topmost node
- **Align Nodes Middle** — aligns all selected nodes to the vertical center
- **Align Nodes Bottom** — aligns all selected nodes to the bottommost node

### Distribute Nodes

You can distribute nodes evenly across the selected range:

- **Distribute Nodes Horizontally** — evenly spaces nodes along the horizontal axis
- **Distribute Nodes Vertically** — evenly spaces nodes along the vertical axis

### Keyboard Shortcuts and Modifiers

#### Double-click a control handle

Removes the control handle from the node, converting it into a sharp corner node.

#### Shift (while dragging nodes)

Constrains node movement to horizontal or vertical directions (90°). This helps maintain precise alignment when editing paths.

## Edit Path Segments

A path segment is the curve or line between two nodes. You can reshape a segment directly without selecting individual nodes.

### Dragging a Segment

Click and drag a path segment to reshape the curve in that area. The control handles of the nearest nodes adjust automatically to follow the drag.

This is useful for quickly sculpting curves without manually positioning handles.

## Combine Paths

`Alt+K`

Joins multiple selected paths into a single compound path while preserving their individual shapes.

This allows several paths to behave as one object while still maintaining their internal structure. Unlike **Unite**, the original shapes are not merged — they remain as separate sub-paths within the compound path.

### How to Use

1. Select two or more paths.
2. Choose **Path → Combine** or press `Alt+K`.

The paths are joined into a single compound path. Overlapping areas between the sub-paths appear as transparent cutouts (using the even-odd fill rule).

To reverse this operation, use [Break Apart](/docs/edit-paths#break-apart).

## Break Apart

`Shift+Alt+K`

Separates a compound path into individual independent paths. Each resulting shape can then be edited separately.

### How to Use

1. Select a compound path.
2. Choose **Path → Break Apart** or press `Shift+Alt+K`.

This is the reverse of [Combine Paths](/docs/edit-paths#combine-paths).

## Reverse Path

Reverses the direction of the path (the order in which nodes are traversed).

This may affect animations, strokes with markers, or path-based effects that depend on path direction.

### How to Use

Select a path, then choose **Path → Reverse Path**.

To set the starting node of a path instead of reversing it entirely, use **Path → Path Start** after selecting the desired node with the Node Tool.

## Mirror Path

The Mirror Path operation allows you to quickly create symmetrical shapes from an open path.

### How to Use

1. Draw half of the desired shape using the Pen Tool.

2. With the Node Tool, select the two open end nodes of the path.

3. Apply **Path → Mirror Path**.

The path is mirrored to the opposite side, creating a perfectly symmetrical full shape.

This technique is useful for creating icons, logos, and other symmetrical illustrations while drawing only half of the design.
