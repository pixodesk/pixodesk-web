# Color

Fill and stroke colours: the colour panel and picker, colour types, gradients, patterns, opacity and used colours.

## Color Panel

The Color Panel allows you to control the visual appearance of shapes using Fill, Stroke, Gradients, Patterns, and Opacity.

You can apply colors to individual layers, groups of layers, or the entire SVG document. Colors are applied according to standard SVG inheritance rules, allowing parent groups to control the appearance of child elements.

### Fill and Stroke Tabs

The Color Panel is divided into two tabs:

- **Fill** — controls the interior color of a shape
- **Stroke** — controls the outline color and style of a shape

### Color Types

For both Fill and Stroke, you can choose from the following color types using the icons at the top of the panel:

- **No Color** — removes the fill or stroke
- **Flat Color** — applies a single solid color
- **Linear Gradient** — applies a color gradient along a straight line
- **Circular Gradient** — applies a radial gradient spreading outward from a center point
- **Pattern** — applies a repeating tiled pattern
- **Unset Color** — removes the color definition so the element inherits color from its parent group

### Color Picker

Below the color type selector, the color picker lets you choose the exact color using a visual wheel or rectangular selector, plus numeric inputs for HEX, RGB, and HSL values.

### Recently Used Colors

Color swatches for colors currently used in the document appear at the bottom of the panel. Click any swatch to quickly apply that color to the selected object.

## Color Picker

The color picker supports two different visual views for selecting colors.

### Color Wheel with Triangle

A circular color wheel combined with a triangular selector for adjusting hue, saturation, and brightness. Drag the outer ring to change the hue, and drag within the triangle to adjust brightness and saturation.

### Rectangular Gradient View

A rectangular color field that allows precise control of hue and color intensity. Use the toggle button above the picker to switch between views.

Both views allow fast and intuitive color selection depending on your preferred workflow.

## Color Models

Colors can be defined using two color models. Toggle between them using the switch above the numeric inputs.

### RGBA

Defines colors using Red, Green, Blue, and Alpha (transparency) values. Each channel ranges from 0 to 255, and Alpha from 0% to 100%.

### HSLA

Defines colors using Hue (0–360°), Saturation (0–100%), Lightness (0–100%), and Alpha values.

### HEX

Colors can also be entered directly as a hexadecimal value in the HEX input field (e.g. `#d41a1a`).

### Alpha

The Alpha channel controls the transparency of the color and is available in both RGBA and HSLA modes.

## Color Types

Both Fill and Stroke support the following color types, selectable from the icon row at the top of the Color Panel.

### No Color

Removes the fill or stroke from the object entirely.

### Flat Color

Applies a single solid color. Use the color picker or numeric inputs to define the exact color.

### Linear Gradient

Applies a gradient that transitions between colors along a straight line. Gradient direction, scale, and position can be adjusted using gradient controls.

### Circular Gradient

Applies a radial gradient that spreads outward from a central point. You can control the center, radius, and focal point of the gradient.

### Pattern

Applies a repeating pattern using a tiled design. Pattern parameters such as translation, rotation, and scale can be adjusted.

### Unset Color

Removes the color definition from the current element so that it inherits color from its parent group.

This is useful for applying a single color to multiple shapes through group styling — set the color on the group and all child shapes with Unset Color will follow it automatically.

## Fill

Fill controls the interior color of a shape. To choose a fill color, you can:

- Select a color from the color picker
- Enter a HEX color value in the input field
- Adjust individual RGBA color values
- Adjust individual HSLA color values

### Fill Opacity

Controls the transparency of the fill color. Lower values make the fill more transparent; 100% keeps the fill fully visible.

### Fill Rule

Defines how the interior of complex or self-intersecting paths is determined when applying a fill.

#### Nonzero

The default rule. Determines the filled region based on the direction of path segments. Areas where the path winding count is not zero are filled.

#### Even-Odd

Determines the filled region by counting how many times a line drawn from a point crosses the path. If the number of crossings is odd, the area is filled; if it is even, the area remains empty.

This rule is useful for creating shapes with holes or cut-out regions inside overlapping paths.

## Stroke

Stroke controls the outline of a shape. To choose a stroke color, you can:

- Select a color from the color picker
- Enter a HEX color value in the input field
- Adjust individual RGBA color values
- Adjust individual HSLA color values

### Stroke Width

Defines the thickness of the outline.

### Line Cap

Controls how the ends of open paths appear.

- **Butt** — flat end cut exactly at the endpoint
- **Round** — semicircular end extending slightly beyond the endpoint
- **Square** — flat end extending slightly beyond the endpoint

### Line Join

Controls how corners between path segments are rendered.

- **Miter** — pointed corner
- **Round** — rounded corner
- **Bevel** — flat cut across the corner

### Dash Array

Creates dashed or dotted stroke patterns. Multiple dash–gap values can be added to create complex dash patterns.

### Dash Offset

Adjusts the starting position of the dash pattern along the path.

### Trim Stroke Effect

Trims the visible portion of a stroke, making it appear to draw on or erase from the path. Enable it by checking **Trim Stroke Effect** in the Stroke section of the Properties Panel.

When enabled, four controls become available:

#### Start / End

Defines the visible portion of the stroke as a percentage of the total path length.

- **Start** — where the visible stroke begins (0% = path start, 100% = path end)
- **End** — where the visible stroke ends (0% = path start, 100% = path end)

Setting Start to 0% and End to 100% shows the full stroke. Narrowing the range hides parts of it. Both values are animatable — keyframe them to create a draw-on or erase effect.

#### Offset

Shifts the entire trimmed segment along the path without changing its length. Animating Offset moves the visible stroke continuously around the path, useful for looping progress indicators or traveling dash effects.

#### Trim All as One

Controls how Trim Stroke Effect behaves when the path has a Dash Array applied.

- **Off** — each dash segment is trimmed independently. Start and End apply to each individual dash.
- **On** — the dashes are treated as a single continuous stroke. Start and End apply to the total combined length of all dashes together.

## Linear and Radial Gradients

Gradients allow smooth transitions between multiple colors. You can add multiple gradient stops with different colors and opacity values.

### Choosing a Gradient Color

To set the color for each gradient stop:

- Select a color from the color picker
- Enter a HEX color value in the input field
- Adjust individual RGBA color values
- Adjust individual HSLA color values

### Editing Gradient Stops

Select the Gradient Tool from the Toolbar to reveal gradient control points on the canvas. Drag the endpoint handles to change the gradient direction and length.

To navigate between stops, use the angle bracket buttons (`<` `>`) next to the color strip to select the previous or next stop. Delete the selected stop using the bin icon.

### Linear Gradient Options

#### Start / End

Defines the gradient direction by setting the start and end points.

#### Position

Moves the gradient within the object.

#### Rotation

Rotates the gradient axis.

#### Scale

Controls gradient stretching.

### Radial Gradient Options

#### Center

Defines the origin point of the gradient.

#### Radius

Controls the size of the gradient circle.

#### Focal Point

Moves the brightest point inside the gradient.

### Gradient Units

Defines how gradient coordinates are calculated.

- **objectBoundingBox** — the gradient is calculated relative to the shape's bounding box
- **userSpaceOnUse** — the gradient uses the document coordinate system

### Spread Method

Defines how the gradient behaves outside its defined range.

- **pad** — extends the outermost color
- **reflect** — mirrors the gradient pattern
- **repeat** — repeats the gradient

## Pattern

Patterns allow shapes to be filled with repeating graphics.

### Applying a Pattern

Choose a pattern from the preset list in the Color Panel. You can also modify patterns using one of two methods:

- In the **Pattern** section in the Properties Panel (below the preset list)
- By double-clicking the pattern in the **Pattern Panel** under the Layer Tree

### Pattern Settings

#### Pattern Fill / Stroke

Defines the color used for pattern tiles.

#### Translation

Moves the pattern within the shape.

#### Rotation

Rotates the pattern tiles.

#### Scale

Resizes the pattern.

#### Tile Start / Tile Size

Defines the pattern grid — the origin point and dimensions of each repeating tile.

Patterns repeat automatically to fill the entire shape area.

## Unset Color

Unset Color removes the color definition from a specific element, allowing it to inherit color from its parent group layer.

### How It Works

For example, multiple shapes inside a group can have their fill or stroke set to Unset. The group itself then defines the fill or stroke color. Changing the color on the group automatically updates all shapes inside it.

This makes it easy to update colors across complex illustrations without editing each shape individually.

## Opacity

Opacity controls the transparency of colors and layers.

### Color Opacity

For flat colors and gradient stops, opacity is adjusted using the **Alpha (A)** slider below the color picker. A value of 100% is fully opaque; 0% is fully transparent.

### Layer Opacity

For pattern fills, opacity should be applied at the layer level in the **Appearance** section of the Properties Panel, rather than through the color Alpha channel.

## Eyedropper

The Eyedropper Tool allows you to sample colors directly from objects on the canvas.

### How to Use

1. Select the object you want to apply a color to.
2. Select the Eyedropper Tool from the Toolbar.
3. Click any element on the canvas to copy its fill or stroke color.

The sampled color is applied to the selected object's active color slot (Fill or Stroke, whichever is currently selected in the Color Panel).

## Used Colors

The **Used Colors** section is the bottom section of the [Objects panel](/docs/edit-objects#object-tree). It
shows every colour currently applied anywhere in the document — across fills, strokes, and
gradients of all objects.

### What it shows

Each colour swatch represents a unique colour value in use. The panel updates automatically as
you add, change, or remove colours in your artwork.

### Using a colour from the panel

Click any colour swatch to apply it to the fill or stroke of the selected object — it becomes the
active colour in the [Properties panel](/docs/edit-objects#properties-panel) and the Toolbar colour picker.
This helps keep colours consistent across the design.

### Replacing a colour everywhere

You can replace a colour across the entire document at once, updating a colour theme without
editing each shape individually:

1. Open the **Edit Color Panel** located under the Layer Tree.
2. Select the colour you want to change across all shapes.
3. Choose a new colour from the Color Wheel or from the Used Colors list.

The new colour immediately replaces the previous colour in all shapes and layers that use it, and
the panel reflects the change.
