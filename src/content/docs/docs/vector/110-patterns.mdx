# Patterns

Pattern fills: create, use, edit and delete them.

## Patterns

Patterns are reusable graphic elements that can be applied as the **Fill** or **Stroke** of any object or group. They are defined once and referenced multiple times, so using the same pattern across many objects does not increase file size.

### Common Uses

- Background textures and decorative fills
- Repeating graphic elements (stripes, dots, grids)
- Complex fills reused across multiple objects
- Consistent styling in illustrations and UI elements
- Animated fills where the same pattern is reused

### Notes

- Patterns are linked — editing a pattern definition updates all objects that reference it
- Only unused patterns (not applied to any object) can be deleted
- In SVG, patterns are stored inside `<defs>` and referenced via `fill` and `stroke` attributes

### The Patterns section

The **Patterns** section of the [Objects panel](/docs/edit-objects#object-tree) lists all pattern definitions
stored in the current document.

A pattern is a reusable tile definition stored in the SVG `<defs>` section. When applied as a
fill, the pattern artwork is repeated (tiled) across the filled area of any object. After creating
a pattern, you can control its translation, rotation, and scale independently for each object it
is applied to.

Each pattern in the list displays a **thumbnail preview** and its name. Patterns that are not
applied to any object are labeled **Unused**, and a red triangle appears next to the collapsed
section header; click the **bin icon** to remove an unused pattern.

Double-click a pattern's thumbnail — or click the **Edit Pattern** button in the
[Properties panel](/docs/edit-objects#properties-panel) when a pattern fill is active — to enter **Pattern
View**, an in-place editing mode showing only the contents of that pattern. Exit Pattern View by
clicking the **`...`** row at the top of the Object Tree. See [Editing patterns](/docs/patterns#editing-patterns).

## Creating Patterns

### How to Create a Pattern

1. Select one or more objects on the canvas.
2. Convert them to a pattern using one of:
   - **Object → Make Pattern** from the menu
   - The **Make Pattern** button in the Top Panel (available when the Selection or Transform Tool is active)

### What Happens After Creation

- The selected object is removed from the canvas and stored as a pattern definition
- The pattern appears in the **Patterns** section of the Objects Panel with a preview thumbnail, labeled **Unused**

From this point, you can apply the pattern as a Fill or Stroke from the Properties Panel.

## Using Patterns

### Applying a Pattern

Patterns can be applied as the **Fill** or **Stroke** of any object or group:

1. Select a shape, object, or group in the Layer Tree or on the canvas.
2. In the Properties Panel, go to the **Color** section.
3. Choose the **Fill** or **Stroke** tab.
4. Click the **Pattern** color type button.
5. Choose a pattern from the dropdown — custom patterns appear at the top.

To ensure the Color section is visible, enable **Show Color options** in the Properties Sections Bar.

> **Note:** If you apply a pattern to a group, make sure all inner layers have their color set to **Unset** so the pattern is visible through them.

### Pattern Transform Options

When a pattern is applied, the **Pattern** subsection appears in the Properties Panel with these controls:

- **Translation** — offsets the pattern within the object (X and Y)
- **Rotation** — rotates the pattern (in degrees)
- **Scale** — scales the pattern (X and Y, in %)

### Duplicating a Pattern

To create a variation of an existing pattern:

- Open the **Patterns** section in the Objects Panel, select a pattern, and duplicate it using standard copy (`Cmd/Ctrl + C`) and paste (`Cmd/Ctrl + V`).
- Or, when a pattern-filled object is selected, click **Duplicate Pattern** in the Properties Panel Color section.

A new unused pattern appears, which you can edit and apply independently.

## Editing Patterns

Editing a pattern definition updates all objects that use it.

### How to Edit a Pattern

You can enter Pattern View in two ways:

- Open the **Patterns** section in the Objects Panel and **double-click** the pattern thumbnail
- Select an object that uses the pattern, then click **Edit Pattern** in the Properties Panel Color section

Once in Pattern View:
- Select shapes directly on the canvas or in the Pattern's Layer Tree
- Modify shapes, paths, colors, and other properties
- Adjust properties in the Properties Panel

To return to the main document, click the **three dots (...)** row at the top of the Pattern's Layer Tree.

Any changes made in Pattern View are automatically applied to all objects using that pattern.

## Deleting Unused Patterns

Unused patterns — those not applied to any object — can be removed to keep your document clean.

### How to Delete

1. Open the **Patterns** section in the Objects Panel.
2. Locate patterns labeled **Unused** (shown with a red label).
3. Click the **bin icon** next to the pattern to delete it.

Patterns that are still applied to one or more objects cannot be deleted until removed from all objects.
