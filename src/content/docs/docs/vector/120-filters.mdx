# Filters

Filter effects: add, configure, edit and remove them.

## Adding Filters

SVG filters can be applied to any shape, object, or group.

### How to Add a Filter

1. Select the layer you want to apply a filter to.
2. In the Properties Panel, scroll to the **Filter** section.
3. Click the **Add Filter** button — a dropdown appears with available presets.
4. Choose a preset to apply it.

### Available Filter Presets

- Drop Shadow
- Inner Shadow
- Outline
- Gaussian Blur
- Motion Blur
- Pixelate
- Warp
- Morphology
- Saturate
- Hue Rotate
- Invert
- Brightness
- Contrast
- Opacity
- Posterize

### Reusing Filters

Once a filter is applied, it is stored in the **Filters** section of the Objects Panel. You can apply the same filter to other layers by selecting them and choosing it from the **Add Filter** dropdown — applied filters appear at the top of the list.

Editing a shared filter updates all layers that reference it.

### Multiple Filters

You can apply multiple filters to the same layer. Each appears as a separate entry in the Filter section of the Properties Panel and can be edited or removed independently.

## Filter Properties

When a filter is applied to an object, it appears as an entry in the **Filter** section of the Properties Panel. Expand the entry to access its properties.

### Filter Region

- **Position** (X, Y) — defines the position of the filter region relative to the object. Controls where the filter effect is rendered; can be used to shift the visible area
- **Size** (X, Y) — sets the dimensions of the filter region. Increase these values to prevent effects like shadows or blurs from being clipped at the edges

Both Position and Size accept a unit (% or px).

### Primitive Units

Determines the coordinate system used for the filter primitives — typically `px`, defining how values like position, size, and offsets are interpreted.

### Shadow-Specific Properties

These appear for shadow-based presets (Drop Shadow, Inner Shadow):

- **Shadow Radius** — controls the blur intensity of the shadow. Higher values produce a softer shadow; lower values produce a sharper edge
- **Offset** (X, Y) — adjusts the horizontal and vertical displacement of the shadow relative to the object
- **Shadow Color** — the color of the shadow

## Filters Section

The **Filters** section of the [Objects panel](/docs/edit-objects#object-tree) lists all filter definitions
used in your document.

A filter applies a visual effect to an object using SVG filter primitives. Effects include blur,
drop shadow, colour adjustments, distortion, and many others. Filters are stored in the SVG
`<defs>` section and can be reused across multiple objects.

### Panel structure

Each filter entry shows:

- the **filter name** (e.g. "Drop Shadow"),
- the **number of objects** it is currently applied to,
- an expandable tree of the **filter primitives** that make up the effect (e.g.
  `<feGaussianBlur/>`, `<feOffset/>`, `<feFlood/>`).

### Shared filters

Filters are defined once and can be shared across multiple objects. When you apply the same
filter to several layers, they all reference the same definition — editing it updates all of them.

Only filters with no objects referencing them can be deleted.

### Editing a filter

Unlike Symbols, Markers, and Patterns, filters do not have a dedicated "Filter View". Filters are
edited inline — click the **Edit** button in the [Properties panel](/docs/edit-objects#properties-panel) next
to the applied filter, or expand the filter in the Filters section and interact with its
primitives directly. See [Editing filters](/docs/filters#editing-filters).

## Editing Filters

### Editing Filter Parameters

Each applied filter appears in the Properties Panel with its name, a preview thumbnail, and an **Edit** button. Click **Edit** to open the filter editor, where you can:

- View the composition graph showing the sequence of SVG filter primitives and how they are connected
- Select individual primitives and modify their parameters in the Properties Panel
- Drag and reorder primitives to change the visual result

### Adding Filter Primitives

In the filter editor, click the **+** (add) button to insert a new primitive. Available primitives are grouped by category:

**Sources**
- Flood, Turbulence, Image

**Modifiers**
- Blur, Drop Shadow, Color Matrix, Component Transfer, Morphology, Convolve Matrix, Offset, Tile

**Combiners**
- Blend, Composite, Merge, Displacement Map

**Lighting**
- Specular Lighting, Diffuse Lighting, Point Light, Spot Light, Distant Light

These primitives can be combined and reordered to create custom filter effects.

### Editing a Shared Filter

If a filter is shared by multiple objects, editing it will update all objects that reference it.

## Remove Filters from Objects

### How to Remove

1. Select the object on the canvas or in the Layer Tree.
2. In the Properties Panel, go to the **Filter** section.
3. Find the filter entry you want to remove and click the **bin icon** next to it.

The filter is removed from the object. If no other objects reference that filter, it is also removed from the **Filters** section in the Objects Panel.

If the same filter is used by other objects, it remains in the Filters panel.
